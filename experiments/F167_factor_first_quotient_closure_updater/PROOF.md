# Proof of the F167 factor-first quotient-closure updater

## 1. Certified common-order input

The supplied order screens show that \(g^M=1\) in every hidden component.
For a prime \(\ell\mid M\), the condition

\[
\gcd(g^{M/\ell}-1,N)=1
\]

shows that no component order divides \(M/\ell\). Since every component
order divides \(M\), it contains the full \(\ell\)-adic part of \(M\).
Doing this for every prime divisor of \(M\) gives

\[
\operatorname{ord}_{R_j}(g)=M
\]

for every \(j\).

The unit group modulo an odd prime power is cyclic. It therefore has a
unique subgroup of each order that divides its size. In particular,
\(H_j=\langle g\rangle\) is the unique local subgroup of order \(M\).

## 2. Proof of the absolute-order trichotomy

Let \(r_j=\operatorname{ord}_{R_j}(d)\). In component \(R_j\),

\[
d^{\Lambda_B}=1
\quad\Longleftrightarrow\quad
r_j\mid\Lambda_B.
\tag{1}
\]

The prime-power factorization of \(\Lambda_B\) contains exactly the prime
powers not larger than \(B\). Hence

\[
r_j\mid\Lambda_B
\quad\Longleftrightarrow\quad
\sigma(r_j)\le B.
\tag{2}
\]

If the condition in (1) holds for a nonempty proper subset of the hidden
components, \(\gcd(d^{\Lambda_B}-1,N)\) is proper. If it holds for none,
the gcd is one and (2) gives \(\sigma(r_j)>B\) for every \(j\). If it holds
for all, the gcd is \(N\) and every \(r_j\) divides \(\Lambda_B\).

Start the divisor-stripping calculation at \(T=\Lambda_B\). For each prime
\(\ell\mid T\), test

\[
\gcd(d^{T/\ell}-1,N).
\tag{3}
\]

A proper result factors \(N\). A result \(N\) says that every local order
still divides \(T/\ell\), so replace \(T\) by \(T/\ell\). A result one says
that no local order divides \(T/\ell\). Because every local order divides
the current \(T\), this last case says that every local order has the same
current \(\ell\)-adic valuation as \(T\).

Repeat until no prime can be removed. On a no-factor run, every prime-adic
valuation of every \(r_j\) is the same, and the final \(T=m\) equals every
\(r_j\). This proves the trichotomy.

It also proves the punctured-bank statement. When the first gcd is one, no
divisor of \(\Lambda_B\) can annihilate any component. When it is proper,
the factor is already known. When it is \(N\), the stripping tests find any
disagreement between local orders. No additional puncture gives another
outcome.

## 3. Merging a common absolute order with the old state

Assume divisor stripping returned the same local order \(m\). Put

\[
L=\operatorname{lcm}(M,m),
\qquad e=L/M.
\]

Inside one cyclic local unit group, the subgroup generated by elements of
orders \(M\) and \(m\) has order \(L\). Therefore

\[
[\langle g,d\rangle:H_j]=L/M=e.
\]

Equivalently, \(dH_j\) has exact order \(e\) in the quotient. Thus
\(d^{eM}=1\) in every component, and F166 applies. Its factor-first order
screens either factor \(N\) or certify the required common orders. Its
prime-primary construction gives one public element of exact common order
\(L\).

Also, \(d^e\) has order dividing \(M\) in every local component. The unique
local subgroup of order \(M\) is \(H_j\), so \(d^e\in H_j\). The
factor-first Pohlig--Hellman calculation can therefore compare its hidden
logarithms to base \(g\). A mismatch gives a factor. Agreement gives the
global relation \(d^e=g^a\).

## 4. Proof of the double-hard certificate

On the branch where the absolute screen is one, Section 2 already gives

\[
\sigma(r_j)>B
\]

for every component. F161 proves that a proper value among

\[
\gcd(d^{eM}-1,N),
\qquad 1\le e\le B,
\]

is a factor, that a first global return gives one common exact local
relative order, and that an all-one scan means every local relative order
exceeds \(B\). Combining the two all-one conclusions gives equation (8) of
the statement.

## 5. The local fingerprint map is an isomorphism

Fix one hidden component and abbreviate

\[
U_j=(\mathbb Z/R_j\mathbb Z)^\times,
\qquad K_j=\langle H_j,d_1,\ldots,d_t\rangle.
\]

Define

\[
\psi_j:K_j/H_j\longrightarrow U_j,
\qquad xH_j\longmapsto x^M.
\tag{4}
\]

This is well-defined because \((xh)^M=x^M\) for \(h\in H_j\). It is a
homomorphism because the local unit group is abelian.

Its kernel consists of cosets represented by elements \(x\in K_j\) with
\(x^M=1\). The cyclic group \(K_j\) contains \(H_j\) of order \(M\).
Therefore \(M\mid|K_j|\), and the kernel of the \(M\)-power map on \(K_j\)
is the unique subgroup of order \(M\). That subgroup is \(H_j\). Hence
\(\psi_j\) is injective.

Its image is generated by the values \(d_i^M\), so it is exactly \(F_j\).
Thus

\[
Q_j=K_j/H_j\cong F_j.
\tag{5}
\]

Both groups are cyclic because they are a quotient and a subgroup of a
cyclic group.

## 6. No-factor comparisons synchronize the fingerprint group

For two public fingerprints \(y,z\), the hidden component \(R_j\) divides
\(y-z\) exactly when the two residues agree in that component. If they
agree in some but not all components, \(\gcd(y-z,N)\) is proper.

The breadth-first search compares every candidate against every stored
value. Therefore, on a no-factor run, any two globally distinct stored
fingerprints are distinct in every hidden component. Projection from the
stored set to each component is injective.

If the queue closes, the stored set is the complete global group \(F\).
Projection \(F\to F_j\) is surjective by the definition of \(F_j\), and it
is injective by the preceding paragraph. Hence it is an isomorphism. With
(5),

\[
F\cong F_j\cong Q_j
\]

for every \(j\). Their common order is \(\kappa=|F|\), and \(F\) is cyclic.

If the search instead stores \(C+1\) values, injectivity still holds on that
stored set. Each \(F_j\), and therefore each \(Q_j\), has at least \(C+1\)
elements. Multiplying by \(|H_j|=M\) gives

\[
|K_j|\ge M(C+1).
\]

This proves the capacity branch without assuming closure.

## 7. Generator recovery and the F166 lift

On the closed branch, factor \(\kappa\). A cyclic group of order \(\kappa\)
contains a generator. Exhaust the stored table and select a value \(y\) for
which

\[
y^{\kappa/\ell}\ne1
\]

for every prime \(\ell\mid\kappa\). The stored predecessor chain gives a
public word \(a\) in the \(d_i\) with \(a^M=y\).

Under the isomorphism (5), the order of \(y\) equals the order of \(aH_j\).
It is \(\kappa\) in every component. Therefore

\[
a^{\kappa M}=1\pmod N
\]

and \(\kappa\) is the common local relative order required by F166. F166
returns a factor or a public state of exact common order \(M\kappa\).

When \(\kappa=1\), this order is unchanged. The conclusion is only that
all supplied blocks lie in the old local subgroups.

## 8. Full alignment is optional for state growth and necessary for global compression

The relation \(a^\kappa\in H_j\) holds in every component. Factor-first
alignment of \(a^\kappa\) either factors \(N\) or returns

\[
a^\kappa=g^b\pmod N.
\tag{6}
\]

For each generator fingerprint, the closed cyclic table gives

\[
d_i^M=(a^M)^{c_i}.
\]

Thus \(x_i=d_i a^{-c_i}\) satisfies \(x_i^M=1\). Aligning \(x_i\) against
\(g\) either factors or gives

\[
d_i a^{-c_i}=g^{b_i}\pmod N.
\tag{7}
\]

If all alignments succeed, (6)--(7) show

\[
\langle g,d_1,ldots,d_t\rangle=\langle g,a\rangle.
\]

The aligned two-generator presentation has exact order \(M\kappa\), so it
is globally cyclic and admits the F161 Smith generator. Without these
alignments, F166 still supplies the next common local order state, but the
old generators and their provenance must remain in the algorithm state.

## 9. Complexity and reset

The factorization of \(\Lambda_B\) is obtained directly from the primes not
larger than \(B\). Its bit length is \(O(B\log B)\). The absolute and
relative screens, divisor stripping, and alignment are polynomial in their
explicit operands and in the relevant bounded prime loops.

The capped BFS processes at most \(O(tC)\) directed generator edges before
closure or the capacity stop. Direct comparison with at most \(C+1\) stored
values gives \(O(tC^2)\) gcds. Factoring \(\kappa\le C\) by trial division,
recovering a generator, and storing predecessor provenance all have
quasipolynomial cost under the stated caps.

After \(M\) changes, the map \(x\mapsto x^M\), the local kernels, and all
fingerprints change. Old quotient tables and capacity counts cannot be
carried forward. Rebuilding them is necessary. Since every strict update at
least doubles \(M<N\), fewer than \(n\) strict updates occur. A
quasipolynomial rescan after each update stays quasipolynomial.

## 10. The source gap

The proof is conditional on a supplied finite block list. A cyclic quotient
of prime order larger than \(C\), synchronized across all hidden components,
makes the BFS reach the capacity branch without a factor. Many named blocks
can remain powers of that same direction. This is the exact F164 obstruction.

P98 shows that actual semiprimes can contain stable powered components above
every prescribed numerical bound. It supports the relevance of large stable
capacity, but its state is not automatically the common-order quotient state
used here. The proof does not identify the two settings.

Therefore neither the absolute-order screen nor capped closure proves an
all-input progress law.
