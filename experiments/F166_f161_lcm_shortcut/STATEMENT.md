# F166 candidate — common local order gives an alignment-free lcm update

## Status and scope

This is a proof-only refinement of F161/P148. It starts after the first
common relative-order return. It shows that hidden-log alignment is not
needed only to construct the next certified common-order state.

The exact result is

\[
\boxed{
\text{factor}
\quad\lor\quad
\text{one public element of exact common order }Me.}
\]

When \(e\ge 2\), the common order grows strictly. When \(e=1\), its order
does not grow. This result does not certify that the new cyclic subgroup is
the full global subgroup \(\langle g,d\rangle\). It does not replace
hidden-log alignment when an exact relation, global subgroup equality, or
the extra factor opportunity is needed. It supplies no released block and
no all-input factoring algorithm.

## 1. Input

Let \(N\ge 3\) be odd. For the proof only, write its unknown prime-power
CRT decomposition as

\[
N=\prod_{j=1}^s R_j,
\qquad R_j=p_j^{\alpha_j},
\]

where the \(p_j\) are distinct odd primes. This decomposition is not input
to the algorithm.

Let \((g,M)\) be a certified common-order state. Thus \(M\) has a supplied
complete factorization,

\[
g^M=1\pmod N,
\qquad
\gcd(g^{M/\ell}-1,N)=1
\quad(\ell\mid M,\ \ell\text{ prime}),
\]

and \(\gcd(M,N)=1\). Hence

\[
\operatorname{ord}_{R_j}(g)=M
\quad(1\le j\le s).
\]

Put \(H_j=\langle g\bmod R_j\rangle\). Let \(d\) be a public unit. Assume
that an F161 common return has certified one integer \(e\ge1\) such that

\[
\operatorname{ord}_{(\mathbb Z/R_j\mathbb Z)^\times/H_j}(dH_j)=e
\quad(1\le j\le s).
\tag{1}
\]

The complete factorization of \(e\) is known, and \(\gcd(e,N)=1\). In the
F161 setting, \(e\) is at most the quasipolynomial cap. Equation (1) gives

\[
d^{eM}=1\pmod N.
\tag{2}
\]

## 2. Factor-first common-order certification for \(d\)

Put \(Q=eM\). Its complete factorization is known. Compute

\[
m=\operatorname{ord}_N(d)
\tag{3}
\]

from the known multiple \(Q\): start with \(m=Q\), and repeatedly replace
\(m\) by \(m/\ell\) whenever \(\ell\mid m\) and
\(d^{m/\ell}=1\pmod N\).

First compute \(\gcd(m,N)\). Return it if it is proper. For every prime
\(\ell\mid m\), compute

\[
E_\ell=\gcd(d^{m/\ell}-1,N).
\tag{4}
\]

Because \(m\) is the exact global order, \(E_\ell\ne N\). Return any
proper value. If all values are one, then

\[
\operatorname{ord}_{R_j}(d)=m
\quad(1\le j\le s).
\tag{5}
\]

This step handles arbitrary odd prime-power components. A partial
prime-power gcd is a valid proper factor.

## 3. Exact lcm identity

On the no-factor branch, local cyclicity gives

\[
\boxed{\operatorname{lcm}(M,m)=Me.}
\tag{6}
\]

Indeed, in each hidden component,

\[
|\langle g,d\rangle_{R_j}|
=M\,|\langle dH_j\rangle|
=Me,
\]

while the subgroup generated by elements of orders \(M\) and \(m\) in a
cyclic group has order \(\operatorname{lcm}(M,m)\).

Put

\[
L=\operatorname{lcm}(M,m)=Me.
\]

This identity is valid when \(M\) and \(m\) share prime factors.

## 4. Public lcm word

For each prime \(\ell\mid L\), put

\[
a_\ell=v_\ell(M),
\qquad
b_\ell=v_\ell(m),
\qquad
t_\ell=\max(a_\ell,b_\ell).
\]

Choose one public \(\ell\)-primary word

\[
y_\ell=
\begin{cases}
g^{M/\ell^{a_\ell}},&a_\ell\ge b_\ell,\\[4pt]
d^{m/\ell^{b_\ell}},&b_\ell>a_\ell.
\end{cases}
\tag{7}
\]

and define

\[
h=\prod_{\ell\mid L}y_\ell\pmod N.
\tag{8}
\]

Every \(y_\ell\) has exact order \(\ell^{t_\ell}\) in every hidden
component. These orders are pairwise coprime. Therefore

\[
\operatorname{ord}_{R_j}(h)=L=Me
\quad(1\le j\le s),
\tag{9}
\]

and \(h\) also has exact global order \(L\). No hidden logarithm and no
negative exponent is used.

The public checks

\[
h^L=1\pmod N,
\qquad
\gcd(h^{L/\ell}-1,N)=1
\quad(\ell\mid L,\ \ell\text{ prime})
\tag{10}
\]

give the next common-order certificate. Since \(L=Me\), its complete
factorization is already known and remains smooth under the F161 cap.

## 5. What this result does and does not preserve

### 5.1 Next certified common-order state

For this purpose, the lcm word is sufficient. In every component,

\[
\langle h\rangle_{R_j}=\langle g,d\rangle_{R_j}
\]

because both groups have order \(L\). Thus later local relative-order tests
can use \((h,L)\) as the new base state.

### 5.2 Full global subgroup

Only

\[
\langle h\rangle\subseteq\langle g,d\rangle
\]

is automatic globally. The inclusion can be strict. Different hidden
relations can make \(\langle g,d\rangle\) a noncyclic subdirect product,
even though every local image is cyclic of order \(L\). Therefore a route
must retain \(g\), \(d\), and their provenance if it skips alignment.

### 5.3 Exact aligned relations and F164-style rank accounting

The lcm word does not give one exponent \(a\) with

\[
d^e=g^a\pmod N.
\]

It therefore cannot replace that row in an integer relation lattice. It
also does not justify replacing all coordinates for \(\langle g,d\rangle\)
by the single coordinate \(h\). F164-style rank and volume arguments still
need alignment, or a separate proof that the discarded generators are
global powers of \(h\).

One can still retain all old words and use \((h,L)\) only as the next
common-order state. A later factor-first alignment against \(h\) can then
recover exact relations or expose a hidden mismatch.

### 5.4 Optional factor opportunity

Hidden-log alignment can factor \(N\) even when the order screens in (4)
all pass. Thus alignment remains useful. The shortcut only proves that it
is not necessary for common-order growth.

When \(e=1\), equation (6) gives \(L=M\). The shortcut gives no growth and
does not prove global membership \(d\in\langle g\rangle\). Alignment is
needed for that classification and can still factor \(N\).

## 6. Exact separating certificates

### 6.1 The F161 \(N=91\) mismatch

For

\[
N=91,
\qquad g=-1,
\qquad M=2,
\qquad d=30,
\qquad e=3,
\]

the global order is \(m=6\). The order screen already gives

\[
\gcd(d^{m/2}-1,N)=\gcd(30^3-1,91)=7.
\]

Thus this case factors before the lcm construction. It is not a
counterexample to the shortcut.

### 6.2 Common local orders do not imply global subgroup equality

Let

\[
N=341=11\cdot31,
\qquad g=202,
\qquad M=5,
\qquad d=277.
\]

Modulo \(11\), take the order-ten generator \(t_1=2\). Modulo \(31\),
take the order-ten generator \(t_2=27\). Then

\[
g=(t_1^2,t_2^2),
\qquad
d=(t_1,t_2^3).
\]

The element \(g\) has exact common order five. The element \(d\) has exact
common order ten. Its local relative order modulo \(\langle g\rangle\) is
\(e=2\) in both components, but

\[
d^2=g^1\pmod {11},
\qquad
d^2=g^3\pmod {31}.
\tag{11}
\]

Both order screens pass:

\[
d^5=-1\pmod {341},
\qquad
d^2=4\pmod {341},
\]

so

\[
\gcd(d^5-1,341)=gcd(d^2-1,341)=1.
\]

The lcm construction returns

\[
h=g d^5=139\pmod {341},
\qquad
\operatorname{ord}_{11}(h)
=\operatorname{ord}_{31}(h)=10.
\]

However,

\[
|\langle g,d\rangle|=50,
\qquad
|\langle h\rangle|=10.
\]

The alignment test exposes the mismatch:

\[
\gcd(d^2-g,341)=11.
\]

This certificate proves the exact boundary. The shortcut constructs the
larger common-order state, but it does not preserve the full global named
subgroup.

For the edge case \(e=1\), keep the same \(N,g,M\) and take \(d=4\).
Then \(d\) has common local order five and lies in each local
\(\langle g\rangle\), but its local logarithms are one and three. The lcm
state stays at order five, while

\[
\gcd(d-g,341)=11.
\]

Thus “no common-order growth” is not the same as global membership.

## 7. Cost and remaining gap

Divisor stripping uses at most \(O(\log Q)\) successful or failed prime
divisions. The order screens and lcm word use one operation per distinct
prime factor of the known integers. All exponents have
\(O(\log N+\log e)\) bits. Under the F161 cap, the complete update has
deterministic quasipolynomial bit cost.

The source gap is unchanged. This result does not construct \(d\), bound
the \(e=1\) branch, or force a first common return below the cap. It only
removes hidden-log alignment from the minimum work needed for a new
common-order state.
