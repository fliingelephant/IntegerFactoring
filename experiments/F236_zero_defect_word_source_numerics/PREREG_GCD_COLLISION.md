# F236 follow-up preregistration: one-dimensional center collision

Use the same complete finite domain.  Put

\[
a=pB^{-1}\pmod q,
\]

and for every integer `1<=d<=n^3` define the centered residue

\[
r_d=[da]_q\in[-(q-1)/2,(q-1)/2].
\]

Freeze outputs for `min_{d<=n,n^2,n^3}|r_d|`: maxima, maxima by input bit
length, all records, and the ten worst cubic-cap inputs.

This tests the exact one-dimensional reformulation of a collision between
the two hidden center indices.  It is evidence only.
