## 2. Compact alignment and the odd-order case

Inside each local order-`M` group, internal roots are exactly the solutions

```

```

solutions. For odd `M`, there is one. A match in only one component gives a
proper gcd, so the no-factor classification is aligned across the two
hidden fields.


hidden choices. In the even case the two candidates differ by
`g^(M/2)=-1`, so testing the two displayed differences also tests both signs.

only other local root is `-g^k`. Mixed hidden signs make the comparison with
