## The actual arithmetic pairing

Write `rep(t)` for the representative in `[-(N-1)/2,(N-1)/2]`, and let U be the units in that interval. All products and inverses below use these representatives. Assume N>1 odd and a,b units.

Lemma 4.3 gives f_a on `{x in U: x<0 and ax<0} union U_positive union {0}`. It swaps 0 and 1. At other x it maps:

- x to x^-1 when x and x^-1 are positive;
- x to a^-1 x^-1 when ax and x^-1 are negative;
- x to -x in the two remaining sign cases.

Its fixed points supply either a nontrivial root of 1 or a square root of a through inversion. The special swap removes the known root 1.

Lemma 4.7 embeds three such domains in `{0,1,2} times rep(Z/NZ)`, of odd cardinality 3N. Define

```
g(x) = (0,-x) if x>=0;
       (1,-x) if x,ax,b^-1 x<0;
       (2,-x) otherwise in its domain.
h(x) = (0,x) if x>0;
       (1,x) if x=0 or x,b^-1 x,ax<0;
       (2,x) otherwise in its domain.
```

The unit-and-zero vertices partition into:

```
A = {0} x U_nonpositive
    union { (1,x): x,ax,b^-1 x>0 }
    union { (2,x): x,ax>0, b^-1 x<0 };
B = {0} x U_positive
    union {(1,0)} union { (1,x): x,ax,b^-1 x<0 }
    union { (2,x): x,b^-1 x<0, ax>0 };
C = {2} x ({0} union { x in U: ax<0 or b^-1 x>0 });
D = { (1,x): x in U and x,ax,b^-1 x do not all have the same sign }.
```

Here U_nonpositive includes zero. The involution r is `g f_a g^-1` on A, `h f_(b^-1) h^-1` on B, `(2,x) -> (2,b f_(ab)(b^-1 x))` on C, and `(1,x)->(1,-x)` on D. Every nonzero nonunit coordinate is fixed. This is an explicit *partial matching with fixed points*, not an implicit directed End-of-Line graph.

The decoder checks gcd(x,N) first. Otherwise it recovers the original f-domain coordinate y: `-x` on A, `x` on B, and `b^-1 x` on C. A nontrivial square root of 1 yields gcd(y-1,N) or gcd(y+1,N). The other cases yield a square root of a, b, or ab; on B, invert the returned root of b^-1. Every accepted factor or root is checked by exact arithmetic. D has no fixed point, and zero coordinates are not fixed points.

## Turning parity into a path

Index vertices by `z=e*N+x+(N-1)/2`. The adjacent matching s fixes 0 and pairs (1,2),(3,4),... . Start at 0, follow r, then s, and stop when r fixes the current vertex. The union of two matchings consists of paths and cycles. The component containing s's unique fixed vertex is a path with an r-fixed other endpoint, unless the start is itself fixed. Thus the walk terminates without cycle detection. Its number of r calls is at most 3N. Arithmetic and branch tests take polynomial bit cost; the algorithm can compute s on demand and keep only the current state. This is an exponential-in-input-length upper bound, not the target bound.

The diagnostic implementation allocates the finite s table for convenience in graph checks. This allocation is charged in the measured resources and is unnecessary for the algorithmic bound.

## A new matching and exact multiplicative macro

Consider instead s(e,x)=(e,-x) for nonzero x; pair (0,0) with (1,0), leaving (2,0) fixed. Start at (2,0). This is another valid second matching on the same 3N vertices.

After leaving zero, every nonzero coordinate encountered lies in the public subgroup H generated by -1,a,b. This follows directly because r and s only invert or multiply by these units; excursions through the three zero vertices reenter at signed monomials in a,b. Therefore this path cannot reach a nonunit-coordinate endpoint. Under the promise that a has Jacobi +1 but is not a square modulo N, and b has Jacobi -1, neither a,b,ab has a square root. Consequently this path must end at a nontrivial root-of-unity decoder. This observation is valid for repeated prime factors as well as squarefree inputs.

Away from the 0/1 swaps and the terminal step, one full r-then-s transition has one of two coordinate forms:

1. Pure label transport: x maps to x.
2. Inverse transport: x maps to -c/x, where
   `c in {1, a^-1, b, b^2, b/a}` modulo N.

The possibilities follow by substituting g,h and the C embedding into f. Two consecutive inverse transports, after any intervening label transports, give the exact macro `x -> (c2/c1)*x`. A repeated prescribed macro word can therefore be powered with logarithmically many modular multiplications.

This identity does **not** certify a jump along the actual path. The coefficient choice depends on the signed representatives of x, ax, b^-1 x and inverses. Those branch predicates must hold at every skipped intermediate state. No efficient all-intermediate certification or endpoint detection is supplied. A prescribed word can be powered cheaply while finding the correct word remains expensive. The matrices all have unit determinant, so their formal composition alone does not create a nonunit denominator.

This is an exact mechanism and a concrete remaining bound, not a claim of novelty relative to all literature. It would be useful to certify long blocks of these signed multiplicative orbits without enumerating them.

## Reproducible finite evidence

`parity_paths.py` implements the source involution, both second matchings, all components for small instances, exact involution checks, and verified endpoint decoders. It retains branch traces, component sizes, endpoint counts, and full instance parameters. The pilot covers every odd N from 3 through 51 and each unit a,b in 1..min(8,N-1): 1,149 instances per matching. Both runs verify `r(r(z))=z` for every vertex and every fixed-point decoder. All paths terminate. The largest adjacent path has 71 r calls; the largest negation path has 34. This is a finite implementation check.

`scaling.py` compares 12 instances per row below with seed 322. Factors are used only to generate and label the explicit diagnostic promise class: a is a nonresidue at both primes and b has opposite local signs. Algorithmic transitions use only N,a,b. ## Random reduction and total-cost obligation

For an all-input algorithm, first handle primality, even numbers and proper powers with polynomial-bit routines and recursive factorization. An odd composite that is not a perfect power has k>=2 distinct prime divisors and is not a square. Its Jacobi character is nonprincipal. Draw residues uniformly, accepting a verified gcd or a unit a with Jacobi +1; separately draw until a verified gcd or a unit b with Jacobi -1. Each loop has expected at most two draws because either nonunits split N or half the units have the desired character. Conditional on accepting a, it is uniform in the Jacobi +1 kernel. Exactly a fraction 2^(1-k) of that kernel consists of squares modulo N, including repeated prime powers. Thus a is not a square with probability at least 1/2. On that event every valid Lemma 4.7 endpoint forces a factor, regardless of how the endpoint is selected.

The complete-path algorithm therefore has constant success probability per attempt and an O(N*poly(log N)) expected bit bound, after repeating square-output failures. A capped walk of T r calls has a different success probability p_T(N); its sufficient contract is `(T*poly(log N))/p_T(N) <= Q(log N)`, including parameter generation and all skipped-state certification work. This packet proves neither a quasipolynomial p_T lower bound nor a quasipolynomial jump cost.

The useful next question is branch-certified multiplicative block traversal, or a second matching that keeps abundant nonunit endpoints while admitting such traversal. PPA membership alone does not pay this cost.
