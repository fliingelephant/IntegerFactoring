## Verdict

**FAIL as written.** Sections 1 and 2 correctly bound the modular subgroup
generated by one fixed root layer. Section 3 then applies that bound to the
whole F154/F156 feedback layer. This step is false because it omits
factor-free integer refinement.

A canonical root can be internal in the old modular subgroup while its
integer representative splits an old named block. The resulting integer
subblocks need not belong to the subgroup generated by the old subgroup and
the roots. Their subgroup can grow by more than a factor of two, and its two
local images need not grow by the same index.

## 1. The explicit fixed-layer theorem passes

Let `x` survive all comparisons with the complete list of `H`. If `x` were
in `H_p`, one list element would match it modulo `p`. The priority rule then
returns a proper gcd unless the same element matches globally. Thus, on the
no-factor, no-membership branch, `x` is outside both `H_p` and `H_q`.

Since `x^2` is in `H`, each local extension has index two. A finite-field
multiplicative group is cyclic, so it has only one subgroup of order
`2|H_r|`. All later roots therefore lie locally in the first extension.
Comparing a later root with the complete list of

```
K = H union x_0 H
```

either finds incompatible hidden preimages by a proper gcd or finds one
global member of `K`. This proves (4) and (5) for the root-generated
subgroup.

The stated gcd bound is also correct for the sequential procedure. Before
the first external root, each input costs `|H|` comparisons. Each remaining
input costs at most `2|H|` comparisons. The total is at most
`2|H||X|`.

The priority rule is essential. A comparison equal to `N` must not stop the
scan before a different comparison can return a proper gcd.

## 2. The compact cyclic theorem passes under all stated hypotheses

The internal solutions are exactly the solutions of

```
2k = a_i (mod M).
```

There are zero or two solutions when `M` is even and one solution when `M`
is odd. On a no-factor branch, each root is therefore internal in both
hidden fields or external in both.

For two external roots, their local ratio is in `<g>`. Squaring gives

```
2k = a_i - a_0 (mod M).
```

This equation is soluble. For even `M`, both exponents are odd because they
are coprime to `M`. For odd `M`, two is invertible. Testing all one or two
solutions detects different hidden choices by a proper gcd. If one choice
matches globally, the root lies in `x_0<g>`.

Finally, `gcd(a_0,M)=1` gives `g` in `<x_0>`, and externality plus
`ord(x_0^2)=M` gives exact local order `2M`. Thus (11) is correct.

## 3. Exact counterexample to the section-feedback conclusion

Take

```
N = 341 = 11 * 31,
g = q_1 = 70,
H = <g> = {1, 70, 126, 295, 190}.
```

The order of `g` is five modulo both hidden primes. Thus `(g,5)` is a
certified common-order state. Define

```
z = 295,
s = 126.
```

The exact identities are

```
z^2 = 70       (mod 341),
z s = 1        (mod 341),
s^2 = g^4      (mod 341),
s^2 g = 1,111,320 = 1 + 3,259 * 341.
```

This is an F154 section-completion instance with `W = F_2`,
`Q(1)=70`, lift `(1,z)`, and canonical inverse representative `s`.
The direct screens are null:

```
gcd(z-s,341) = gcd(z+s,341) = 1.
```

The complete F159 priority scan is also null except for global membership:

```
h                 1   70   126  295  190
gcd(s-h,341)      1    1   341    1    1
```

The compact test solves `2k = 4 (mod 5)`, obtains `k=2`, and confirms
`s=g^2`. Therefore the root-generated subgroup does not change:

```
<H,s> = H.
```

But the integer representative gives the factor-free split

```
gcd(70,126) = 14,
70 = 14 * 5.
```

The refined named subgroup is

```
H' = <14,5>.
```

It has the following exact sizes:

```
                 global   modulo 11   modulo 31
H                   5          5           5
H'                 75          5          15
index               15         1           3
```

For example, modulo 31 the element `14` has order 15 because
`14^3=16`, `14^5=5`, and `14^15=1`. Modulo 11, both new blocks remain in
the old order-five subgroup. Thus the new named subgroup grows by global
index 15, with unequal local indices. It is neither inert nor one common
doubling.

This does not refute Sections 1 or 2. It shows that those sections control
only `<H,X>`. They do not control the subgroup generated after the integer
encodings in `X` refine the named blocks of `H`. That omitted channel is
the central purpose of F154/F156.

## 4. Required repair

The candidate can be repaired without changing Sections 1 and 2:

1. Restrict (13) to the modular subgroup generated by `H` and the section
   root residues **before integer refinement**.
2. State that the theorem gives no bound on subgroup growth from factors of
   old integer blocks exposed by the canonical representatives.
3. Do not conclude that recursive roots or alignment disagreement are the
   only routes to the F158 capacity cutoff. Refinement-created generators
   remain a third route.
4. In the compact F154/F156 specialization, require explicitly for every
   tested representative an exponent presentation
   `s_v^2=g^{a_v}` with `gcd(a_v,M)=1`. A certified cyclic presentation of
   `H` alone does not imply this coprimality condition.

With these changes, F159 would give a clean saturation theorem for one
root-generated residue layer. It would not close the refinement-feedback
route.
