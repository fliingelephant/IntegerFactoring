# Proof of F195

## 1. Reduction of a coprime exact order

Fix \(p^a\mid N\). The reduction map

\[
(\mathbb Z/p^a\mathbb Z)^\times
\longrightarrow
(\mathbb Z/p\mathbb Z)^\times
\]

has a finite \(p\)-group kernel. The cyclic group generated by \(g\) has
order \(M\), coprime to \(p\) by (3). Its intersection with that kernel is
therefore trivial. Reduction is injective on \(\langle g\rangle\), and

\[
\operatorname{ord}_p(g)=M.
\]

Fermat's theorem gives \(M\mid p-1\). This proves (4). The published
Gao--Feng--Hu--Pan corollary applies with \(s=1,m=M\), proving (5) and (6).

For the comparison, the balanced enumeration cost
\(\sqrt N/M^2\) is QP exactly when \(N^{1/4}/M\) is QP, up to replacing one
numerical-QP bound by its square. Thus the new result improves the terminal's
cost and scope, not the exponent threshold class.

## 2. Exact Harvey--Hittmeir control flow

Algorithm 3.1 initializes its accumulated element and order to \(1,1\), and
then scans \(\beta=2,3,\ldots\). If the initial test \(2^D<N\) holds, the
algorithm already returns \(2\), whose order must exceed \(D\). Otherwise it
reaches the loop.

For odd \(N\), \(2\) is a unit and does not divide \(N\). It is not in the
initial trivial subgroup. Lemma 2.1 searches its order through \(D\). Under
(7) it returns the result “order above \(D\),” so line 10 returns \(2\).
The later accumulation and smooth-number lines are not executed.

Equation (2) is QP for numerical-QP \(D\). For \(D=N^\delta\), its main
factor is \(N^{\delta/2+o(1)}\). This work occurs before the algorithm returns
and does not produce a smaller input. The one-child recurrence therefore has
no bearing on this per-node bound.

## 3. Rank-three scale

The published balanced-semiprime parameter range and list formula give (8).
Since \(m<N^{1/4}/2\),

\[
m^{3/2}<2^{-3/2}N^{3/8},
\]

so (8) implies (9), up to an absolute constant. If \(m=N^a\), the exponents
of the two main terms in (10) are

\[
a
\quad\text{and}\quad
\frac12-\frac{3a}{2}.
\]

They are equal at \(a=1/5\).

If every local order of \(\alpha\) exceeds \(C\), then an exponent
\(e\le C\) cannot annihilate any local component. Applying this to
\(e=m^2i\), \(1\le i\le k\), yields (11) as the direct order-bound
interface. Substitution of (8) gives (12).

If instead every local order is \(T\)-rough, then an exponent composed only
of primes at most \(T\) is coprime to the local order and cannot annihilate a
nonidentity element. Covering every \(i\le k\) this way requires at least
\(T\ge k\). Equation (9) is therefore still outside numerical QP.

## 4. The low/high fork

For each rational prime \(\beta\le B\), first compute \(\gcd(\beta,N)\). If
it is proper, factor. Otherwise use the published order search through \(D\).
If the exact order \(m\le D\) is found, factor \(m\) and, for every prime
\(r\mid m\), screen

\[
\gcd(\beta^{m/r}-1,N).
\]

A proper result factors. A global result is impossible because \(m\) is the
exact order modulo \(N\). If every result is one, each hidden local order
contains the full primary part of \(m\) for every \(r\mid m\), and hence
equals \(m\). Thus case 2 is synchronized and exact. If the search reports
order above \(D\), case 3 holds.

Assume every scanned prime is synchronized low. Their order lcm \(M\) then
annihilates every prime \(\beta\le B\) modulo every hidden rational prime
\(p\). Since the scan also proves \(p>B\), every \(B\)-smooth integer
\(x\le p\) is a nonzero product of those primes and satisfies

\[
x^M=1\pmod p.
\]

There are at most \(M\) roots of \(X^M-1\) in \(\mathbb F_p\), proving
(13). For a numerical-QP choice such as
\(B=\exp((\log(n+2))^3)\), standard smooth-number lower bounds yield

\[
\log\Psi(p,B)=\log p-o(\log p)
\]

when \(\log p=\Theta(n)\). Hence \(M=p^{1-o(1)}\). On the balanced promise
\(p=N^{1/2+o(1)}\), so eventually \(M>N^{1/4}\) by an exponential margin,
and Theorem 1 applies. Here \(\gcd(M,N)=1\) follows because each common
order divides both \(p-1\) and \(q-1\).

The scan is numerical QP: it uses a numerical-QP number of rational primes,
and every bounded order search has numerical-QP cost. The proof gives no
terminal for the mixed branch containing high-order primes.

Finally, the displayed power-of-two carry identities reduce modulo every
hidden factor to \(x_{e+1}=2x_e\). They do not supply the factor-specific
integer data required by either cited algorithm. This is only an interface
observation, not an impossibility theorem.
