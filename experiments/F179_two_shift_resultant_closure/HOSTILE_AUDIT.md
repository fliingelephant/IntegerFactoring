## Hostile checks

### F178 interface and prime-power semantics

The imported F178 hard branch supplies exactly the hypotheses used here:

\[
f_j>1,\qquad \gcd(f_j,N)=1,\qquad \sigma(f_j)>T\ge n.
\]

For every integer exponent \(e\), the definition of the local order gives

\[
y^e\equiv1\pmod{R_j}\quad\Longleftrightarrow\quad f_j\mid e.
\]

There is no hidden repeated-prime failure. If \(R_j=p_j^{u_j}\), the kernel
of reduction from \((\mathbb Z/R_j\mathbb Z)^\times\) to
\((\mathbb Z/p_j\mathbb Z)^\times\) is a \(p_j\)-group. Since
\(p_j\nmid f_j\), the cyclic subgroup generated by \(y\) meets that kernel
trivially. Thus a tested power is one modulo \(p_j\) exactly when it is one
modulo all of \(R_j\). Consequently each scan gcd is a product of complete
hidden components. Even without using this strengthening, any partial
prime-power gcd would already be a proper factor.

### Gcd scans and the two action conclusions

On a no-factor execution, every scan value is therefore either \(1\) or
\(N\). A global value \(N\) at index \(k\) says that every \(f_j\) divides
\((N+\delta)^k-1\). If no global value occurs, no local order divides any
displayed exponent; otherwise the gcd would be nontrivial.

For \(\delta=0\), F178 gives \(\gcd(N,f_j)=1\), so the least positive return
index is \(\operatorname{ord}_{f_j}(N)\). Absence through \(K\) proves the
strict bound \(\operatorname{ord}_{f_j}(N)>K\) for every component.

For \(\delta=3\), the order is defined only when
\(\gcd(N+3,f_j)=1\). In that unit case, the same absence argument proves
\(\operatorname{ord}_{f_j}(N+3)>K\). In the nonunit case, a common prime
divides \(N+3\), while every positive power is zero modulo that prime and
cannot be one modulo \(f_j\). This proves exactly the componentwise
disjunction in (7)--(8). It gives no factor of \(N\), and the candidate does
not claim one.

The first global return need not be the exact order for each component. The
proof uses it only as a common annihilating exponent, which is sufficient.

### Integral resultant divisibility

Global returns at \(a,b\) give, for every \(j\),

\[
f_j\mid P(N),\qquad f_j\mid Q(N).
\]

The required Bezout identity is genuinely integral. The Sylvester matrix
has integer entries, and its adjugate expresses its determinant as an
integer linear combination of the shifted coefficient vectors of \(P\) and
\(Q\). Equivalently, there are \(A,B\in\mathbb Z[X]\) with

\[
A P+B Q=\operatorname{Res}(P,Q).
\]

Evaluation at the integer \(N\) therefore proves
\(f_j\mid\operatorname{Res}(P,Q)\), and hence \(f_j\mid R\). No rational
denominator or primitive-part assumption is missing.

### Nonvanishing and size

A common complex root would satisfy both \(|z|=1\) and \(|z+3|=1\). But

\[
|z+3|\ge 3-|z|=2,
\]

so the resultant is nonzero. Since \(P\) is monic,

\[
R=\prod_{z^a=1}|(z+3)^b-1|.
\]

For every factor, \(|z+3|\le4\), and for \(b\ge1\),

\[
|(z+3)^b-1|\le4^b+1<2^{2b+1}.
\]

Thus

\[
0<\log_2 R<a(2b+1)\le K(2K+1)=O(K^2).
\]

In the two-return branch, \(R\ne1\) also follows from \(f_j>1\) and
\(f_j\mid R\).

### Exact computation and QP cost

The Sylvester matrix has dimension \(a+b\le2K\). The coefficients of
\((X+3)^b-1\) have \(O(b)\) bits, so fraction-free determinant computation
produces the exact integer resultant in bit complexity polynomial in
\(K\) and its \(O(K^2)\)-bit output. No numerical root computation is
needed.

Trial division through \(\sqrt R\) uses

\[
2^{O(K^2)}=2^{O((\log n)^{2c})}
\]

bit operations, including polynomial-bit-cost divisions. This is uniform
deterministic QP because \(c\) is fixed. It yields the complete
factorization needed by the stripping step.

There are only \(2K\) scan powers. For \(k\le K\), the exact exponent
\((N+\delta)^k-1\) has \(O(Kn)\) bits, so its construction and modular
exponentiation are polynomial in \(n\) and \(K\). The stripping exponents
have \(O(K^2)\) bits, and the number of successful prime deletions plus
terminal prime tests is \(O(\log R)=O(K^2)\). These costs are below the
trial-division bound.

### Factor-first exact order recovery

Let \(M\) be the current divisor of \(R\). The invariant is
\(f_j\mid M\) for every \(j\). For a prime \(\ell\mid M\), testing

\[
G=\gcd(y^{M/\ell}-1,N)
\]

has three exhaustive outcomes. If \(G=N\), every local order divides
\(M/\ell\), so deleting \(\ell\) preserves the invariant. If \(G\) is
proper, it is already a factor. If \(G=1\), no local order divides
\(M/\ell\).

At the terminal test for \(\ell\), unequal values of
\(v_\ell(f_j)\) would make exactly the lower-valuation components return
one modulo their full \(R_j\), producing a proper gcd. Hence a no-factor
terminal test forces

\[
v_\ell(f_j)=v_\ell(M)
\]

for every \(j\). Applying this to every prime in \(M\) proves that the
terminal value is the common exact order \(m=f_j\) for all components. Its
complete factorization is inherited from the factorization of \(R\).
Finally,

\[
\sigma(m)>T\quad\Longrightarrow\quad m>T\ge n,
\]

so the claimed state is strictly above the input length.

### Exhaustiveness and quantifiers

After any proper gcd, the procedure returns a factor. On the remaining
execution, either the zero-shift scan has no global return, or it has one.
In the latter case, either the three-shift scan has no global return, or it
also has one. These are exactly the long/nonunit and two-return cases. The
two-return case then either factors during stripping or returns the exact
common-order state. This exhausts all executions.

The QP constant may depend on the fixed \(c\), as stated. No assertion is
made for a growing \(c\), no existence of a short return is assumed, and
the surviving nonunit relation is only the componentwise alternative
displayed in the statement.

There is one harmless notation typo in the statement: `D_{s,k}` in the
scan classification clearly refers to `D_{\delta,k}`. It does not change
any quantifier or branch.
