# F121 — private-row feedback is only Laurent completion

## Verdict

Let

\[
N=2q-1>3
\]

with `q` prime. Promoting `q` does not create a new multiplicative generator.
It names the old unit `2^{-1}`. Every word that uses `q` is an old word with
a signed exponent of `2`.

This distinction is essential:

- **Recognition only:** `q` is already a seed-basis block, and `(2,q)` is
  already the frozen pair for seed `2`. No source rule changes.
- **New pairing permission:** authorizing `(a,q)` for other seeds is outside
  the declared complete all-pairs source. It can add canonical residues to
  the finite bounded language.
- **Algebraic generation:** the generated subgroup does not grow. Every new
  group element is a Laurent word in the old generators.
- **Exact-value generation:** it need not follow residue generation. At
  `N=4033`, the new permission adds 50 residues and zero exact columns.

The stable private row survives every such extension. It refutes `REUSE`.
It does not force `CLOSE` or `ROOT`.

## 1. Universe-private-row theorem

For a unit `c` with `1 <= c < N`, let `w` be its least positive inverse and
put

\[
P_N(c)=cw.
\]

### Theorem 1

For every odd prime `q` and `N=2q-1`,

\[
q\mid P_N(c)
\quad\Longleftrightarrow\quad
\{c,w\}=\{2,q\}.
\]

In that case

\[
P_N(c)=2q=N+1,
\qquad v_q(P_N(c))=1.
\]

Thus row `q` occurs in exactly one column in the complete universe of
distinct canonical exact values. It remains private under every canonical
word extension, including arbitrary future use of the named block `q`.

### Proof

If `q` divides `cw`, primality gives `q|c` or `q|w`. Both endpoints lie in
`[1,2q-2]`. The only positive multiple of `q` in this interval is `q`.
Since

\[
2q=N+1\equiv1\pmod N,
\]

the canonical inverse of `q` is `2`, and the canonical inverse of `2` is
`q`. The converse is immediate. Since `q` is odd, `v_q(2q)=1`. Exact-value
deduplication merges the two endpoint orders. This leaves one column. ∎

The excluded edge case is `q=2`, `N=3`. There `P_N(2)=4` has even
`2`-valuation, so it is not the claimed odd private row.

## 2. What naming `q` changes

The seed-`2` relation is already

\[
(c,w,P)=(2,q,2q).
\]

The deterministic endpoint refinement must retain `q` as a prime integer
block. The support of this relation is exactly `{2,q}`. Hence its declared
frozen pair is `(2,q)`.

Also,

\[
q\equiv2^{-1}\pmod N.
\]

Therefore the two frozen orientations are

\[
[2^e q]_N=[2^{e-1}]_N,
\qquad
[2q^e]_N=[2^{1-e}]_N.
\]

Recognition of `q` only gives a signed, or Laurent, completion of the old
`2` trajectory. It is not new-block feedback of the P78 type. No integer
endpoint split has enlarged the block-generated subgroup.

If a new policy also authorizes `(a,q)`, then

\[
[a^e q]_N=[a^e2^{-1}]_N,
\qquad
[aq^e]_N=[a2^{-e}]_N.                 \tag{1}
\]

More generally, replacing every occurrence of `q^t` by `2^{-t}` removes
`q` from any word. This proves the Laurent reduction for every number of
uses of `q`.

Equation (1) does not say that a bounded nonnegative-exponent source already
enumerated every reduced residue. Negative exponents can add elements to the
finite source language. They cannot add an algebraically independent
generator.

## 3. Exact kernel effect

Let `M` be any exact-value parity matrix that contains `P=N+1`. Theorem 1
makes row `q` equal to a unit vector at that column. Every `x in ker(M)` must
therefore have coefficient zero at `P=N+1`.

Delete the private row and its column. Restriction gives an isomorphism from
the old kernel to the kernel of the remaining matrix. Every selected product
is unchanged because the deleted coordinate was zero. The positive-exact-root
map is unchanged too.

Consequently:

- the private row cannot be reused by feedback;
- the protected column cannot participate in a square dependency;
- peeling it neither creates nor destroys a dependency among other columns;
- peeling it preserves every surviving global or non-global root class.

New Laurent words can still add other exact columns. Whether those columns
close, and whether a closed product has a non-global root, are separate
questions. The private-row theorem supplies neither result.

## 4. Registered comparison at `N=4033`

The fixed replay used

```text
N = 4033 = 37*109
n = 12
B = 144
q = 2017
2q = N+1
```

It passed all registered checks after one preserved reporting failure.

### 4.1 Recognition and static source

The deterministic seed basis contains `q=2017`. Its seed-`2` frozen pair is
exactly `(2,2017)`. The order of `2` modulo `4033` is 36. The static source
already sees the full subgroup generated by `2`.

The no-stop static replay gave:

```text
attempted source positions       19,151
first canonical residues          2,737
distinct nonunit exact values       869
exact matrix rank                   522
exact matrix nullity                347
```

In the full canonical-unit universe there are 927 distinct nonunit exact
values. Only

```text
P = 4034 = 2*2017
```

has odd `2017`-valuation. This is the universe-level private row from
Theorem 1, not only a source enumeration observation.

### 4.2 Hypothetical one-step pairing

The registered extension attempted both orientations of `(a,q)` for every
`a=2,...,12` and every `e=0,...,144` after the full static source.

```text
candidate attempts                         3,190
distinct candidate residues                  640
new canonical-residue first occurrences       50
new distinct exact values                       0
```

All 3,190 candidates passed the two identities in (1). Thus the extension
does enlarge the bounded canonical-residue language. It does not enlarge the
exact-value matrix on this input. Static and promoted matrices have the same
869 columns, rank 522, nullity 347, kernel-basis hash, and root counts.

This is an exact counterexample to treating residue-language growth as
exact-square-class growth.

### 4.3 The four feedback endpoint hits are old hits

Four of the 50 new residues have a proper endpoint sign gcd. Each new residue
is the inverse endpoint of an earlier static record. The same sign screen was
therefore already performed.

| feedback endpoints | gcd | earlier static endpoints | earlier provenance |
|---|---:|---|---|
| `(1264,3213)` | `gcd(c+w,N)=37` | `(3213,1264)` | frozen `(2,3)`, `e=46` |
| `(2707,660)` | `gcd(c+w,N)=37` | `(660,2707)` | frozen `(2,3)`, `e=28` |
| `(3114,1141)` | `gcd(c+w,N)=37` | `(1141,3114)` | frozen `(2,3)`, `e=10` |
| `(1091,2181)` | `gcd(c-w,N)=109` | `(2181,1091)` | all-pair `(2,11)`, `e=93` |

The plus screen is invariant under endpoint exchange. The minus screen only
changes sign, which does not change its gcd. These four factors were not
inferred from a prior dependency. They were emitted directly at earlier
static inverse representatives. Feedback adds no endpoint-screen success.

### 4.4 CLOSE and ROOT already occur before feedback

The static seed `c=4` has canonical inverse `w=3025` and

\[
P_N(4)=4\cdot3025=12100=110^2.
\]

Its parity column is zero. The singleton column already proves `CLOSE`. Its
positive exact root is `110`, and

\[
110^2\equiv1\pmod{4033},
\]

with

\[
\gcd(110-1,4033)=109,
\qquad
\gcd(110+1,4033)=37.
\]

Thus the same static singleton already proves `ROOT`.

The declared all-pair word `(10,11,e=1)` also gives residue `110`, but it is
later than the seed-`4` exact value and is deduplicated. It is not a feedback
witness. Neither `CLOSE` nor `ROOT` can be attributed to promotion.

## 5. REUSE, CLOSE, and ROOT

| Claim | General conclusion | `N=4033` comparison |
|---|---|---|
| `REUSE` | False. Row `q` is private in the entire canonical exact-value universe. | Row `2017` occurs only in `P=4034`, both before and after promotion. |
| `CLOSE` | Not forced by the private row or Laurent reduction. It needs a separate rank relation among other columns. | True before promotion. Promotion adds no column and changes nothing. |
| `ROOT` | Not forced by `REUSE` failure or by `CLOSE`. It needs a non-global positive exact root. | True before promotion from `P=12100`. Promotion changes nothing. |

The strongest exact statement is therefore asymmetric. The feedback route
cannot repair the stable `q` row. It can expand a bounded residue grammar,
but only through inverse powers of `2`. Any later `CLOSE` or `ROOT` must come
from the remaining exact columns and requires independent proof.

## 6. Scope

The registered run is a mathematical no-stop replay. The operational source
would stop in its trial screen because `gcd(37,4033)=37`. The replay is used
only to compare complete static and promoted grammars.

The zero-new-exact-value result is specific to `N=4033` and the registered
one-step policy. No general theorem here says that Laurent pairing can never
add another exact value. The general theorem says only that it can never
reuse row `q`, never enlarge the generated subgroup, and never obtain
`CLOSE` or `ROOT` from the private column itself.
