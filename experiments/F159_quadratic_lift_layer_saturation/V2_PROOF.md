# Proof of F159 V2 root-layer saturation and refinement boundary

## 1. Local quadratic layers

For \(r\in\{p,q\}\), let \(H_r\) be the image of \(H\) in
\(\mathbf F_r^\times\). If \(x_r^2\in H_r\), then the coset \(x_rH_r\)
has order at most two in the quotient generated by it. If
\(x_r\notin H_r\), then

\[
[\langle H_r,x_r\rangle:H_r]=2.
\tag{33}
\]

The ambient multiplicative group is cyclic. It has one subgroup of each
order. Hence all external elements whose squares lie in \(H_r\) generate
the same subgroup of order \(2|H_r|\).

## 2. Exhaustiveness and cost of the explicit scan

Suppose \(x_p\in H_p\). Some public \(h\in H\) matches \(x\) modulo \(p\).
The gcd \(\gcd(x-h,N)\) is proper unless the same element matches globally.
The priority scan therefore classifies every root on a no-factor branch as
globally internal or external in both local components.

Let \(x_0\) be the first external root. Its two local images give the unique
index-two extensions. Thus every later root belongs to the image of

\[
K=H\sqcup x_0H
\]

modulo each hidden prime. If the two local preimages in the complete list
\(K\) disagree, a comparison returns a proper gcd. If no proper gcd occurs,
one comparison returns \(N\), so the root is globally in \(K\). This proves
(4) and (5).

If the first external root is in position \(t\), the work before and
including it is \(t|H|\) gcds. The remaining \(|X|-t\) roots use at most
\(2|H|\) gcds each. The total is at most \(2|H||X|\). If no external root
exists, the cost is only \(|H||X|\).

## 3. Compact alignment

Inside the cyclic local subgroup \(\langle g_r\rangle\) of order \(M\),
the internal roots of \(g_r^{a_i}\) are exactly \(g_r^k\) with

\[
2k\equiv a_i\pmod M.
\]

A match in only one hidden field gives a proper gcd. Hence every root is
globally internal or external in both fields on the no-factor branch.

Fix the first external root \(x_0\). Local uniqueness of the index-two
extension gives

\[
x_i=x_0g^{k_r}\pmod r
\]

for every other external root and some \(k_r\pmod M\). Squaring gives

\[
2k_r\equiv a_i-a_0\pmod M.
\]

If \(M\) is odd, this has one solution. If \(M\) is even, coprimality in
(7) makes \(a_i,a_0\) odd, so their difference is even; the equation has
two solutions. Testing all solutions detects incompatible hidden choices.
Otherwise one candidate matches globally, and
\(x_i\in x_0\langle g\rangle\).

Choose \(b\) with \(a_0b\equiv1\pmod M\). Since \(g^M=1\pmod N\),

\[
g=(x_0^2)^b\in\langle x_0\rangle.
\]

Also \(x_0^2=g^{a_0}\) has exact order \(M\) locally. If \(x_0\) had local
order \(M\), cyclic uniqueness would put it in \(\langle g_r\rangle\),
contrary to externality. Therefore its local order is \(2M\). This proves
(11).

If \(M\) is odd, equation (8) has one solution \(k_i\). In each hidden
field, the only two square roots are \(g^{k_i}\) and \(-g^{k_i}\). The
internal case matches the first globally. In the external case, a different
sign in the two fields makes the comparison with \(g^{k_i}\) return a
proper gcd. Hence a no-factor external root is globally \(-g^{k_i}\). This
proves the odd-order qualification and identifies the only extension as
\(\langle g,-1\rangle\).

## 4. Why integer refinement escapes the theorem

The root theorem is a statement in the residue group. An integer equality

\[
b=d(b/d)
\]

only puts the product of the two new block residues in \(H\). It does not
put either residue in \(H\), in \(X\), or in \(\langle H,X\rangle\). Thus
there is no quotient-exponent-two argument for the refined named subgroup.

This is not a logical corner case. The following certificate realizes the
separation under the compact common-order assumptions.

## 5. Exact post-refinement local-membership screen

Let \(H=\langle g\rangle\) with
\(\operatorname{ord}_p(g)=\operatorname{ord}_q(g)=M\). Since \(M\) divides
both \(p-1\) and \(q-1\), the solutions of

\[
y^M=1
\]

in either cyclic field group form the unique subgroup of order
\(\gcd(M,r-1)=M\), namely \(H_r\). Therefore

\[
r\mid d^M-1
\quad\Longleftrightarrow\quad
d_r\in H_r
\qquad(r\in\{p,q\}).
\]

Taking the gcd with the squarefree semiprime \(N=pq\) gives exactly the
three rows of (15). If the gcd is one, \(d_r\notin H_r\) in both fields, so
both \(\langle H_r,d_r\rangle\) strictly contain \(H_r\). No claim about
their indices or a new common-order certificate follows.

If the gcd is \(N\), both local memberships hold, but their exponents with
respect to \(g_p\) and \(g_q\) can differ. Hence this screen alone does not
prove global membership in the diagonal subgroup \(H\).

## 6. Verification of the \(N=341\) certificate

Direct modular multiplication gives

\[
70^0,70^1,70^2,70^3,70^4
\equiv
1,70,126,295,190\pmod{341}
\]

and \(70^5\equiv1\). Modulo \(11\), \(70\equiv4\) has order five.
Modulo \(31\), \(70\equiv8\) has order five. Hence the displayed list is
the complete global subgroup and \((70,5)\) is certified common-order.

The identities

\[
295^2\equiv70,
\qquad
295\cdot126\equiv1,
\qquad
126=70^2
\pmod{341}
\]

prove the modular part of (18), (21), and (26). The old square
representative is \(t=467\equiv126\pmod{341}\), so

\[
t^{-1}\equiv295\pmod{341},
\qquad
\gcd(t,70)=1.
\]

Exact integer arithmetic gives the legal base record

\[
467^2\cdot70
=15{,}266{,}230
=1+44{,}769\cdot341.
\]

It has one nonzero parity column, so its binary square-dependency kernel is
zero. The canonical completion record is

\[
126^2\cdot70=1{,}111{,}320=1+3{,}259\cdot341.
\]

Furthermore,

\[
295-126=169,
\qquad
295+126=421,
\]

and neither integer is divisible by \(11\) or \(31\). The differences from
the ordered subgroup list are

\[
125,56,0,-169,-64,
\]

which give exactly the first gcd vector in (24). For \(z=295\), the
differences are

\[
294,225,169,0,105,
\]

which give the second gcd vector in (25). The direct screens for \(70\) and
for the refined blocks are also one by immediate division by \(11\) and

The integer gcd is \(\gcd(70,126)=14\), so the old block splits into the
coprime units \(14\) and \(5\).

Modulo \(11\), both new residues belong to the old order-five subgroup:

\[
\langle14,5\rangle_{11}

\]

which has size five. Modulo \(31\),

\[

\qquad

\]

and neither the third nor fifth power is one. Thus \(14\) has order 15 and

For the global size, the refined group contains

\[

\]

which has order five, and

\[

the old order-five subgroup modulo \(11\) and outside it modulo \(31\).

## 7. Scope

The root-layer saturation theorem survives unchanged. What fails is using
it as a saturation theorem for refinement-created integer generators.
F154/F156 deliberately expose those generators, so their refinement route
remains open. The example proves finite capability only. It supplies no
all-input source law, useful-refinement density, recursion bound, or
quasipolynomial factoring algorithm.
