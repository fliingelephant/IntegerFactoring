# Proof of F195 V2

## 1. Exact common order

For \(p^a\mid N\), the reduction kernel

\[
(\mathbb Z/p^a\mathbb Z)^*\longrightarrow(\mathbb Z/p\mathbb Z)^*
\]

is a \(p\)-group. The cyclic group generated by \(g\) has order \(M\),
coprime to \(p\) by (2). Its intersection with the kernel is trivial.
Reduction is therefore injective on \(\langle g\rangle\), so

\[
\operatorname{ord}_p(g)=M.
\]

Thus \(M\mid p-1\), so \(p\equiv1\pmod M\). Also \(M<N\) and
\(M\in(\mathbb Z/N\mathbb Z)^*\). All hypotheses of the published
Corollary 3.2 hold with \(s=1,m=M\), proving (4) and (5).

If \(A=N^{1/4}/M\), the balanced terminal costs are \(A\) and \(A^2\), up
to polynomial factors and ceilings. One is numerical QP exactly when the
other is. This proves the threshold comparison.

## 2. Beta-two control flow

The fixed lookup line is excluded by \(N\ge N_0\), and oddness excludes the
line-2 factor. If \(2^D<N\), line 3 returns \(2\). Its powers through \(D\)
are distinct positive integers below \(N\), so its order exceeds \(D\).

Otherwise lines 5--6 initialize \(M=1\) and start with \(\beta=2\). Line 7
does not return because \(N\) is odd. Line 8 does not skip because
\(2^1\ne1\pmod N\). Under (6), Lemma 2.1 reports order above \(D\), and
line 10 returns \(2\). Lines 11--19 are not reached.

Equation (7) is the published Theorem 1.1 bound. Numerical-QP \(D\) makes it
QP. If \(D=N^\delta\), its main factor is \(N^{\delta/2+o(1)}\), paid before
any output. This verifies the recursion distinction.

## 3. Rank-three parameter floor

At the balanced exponent \(1/2\), the published legal range gives

\[
m^{3/2}<2^{-3/2}N^{3/8}.
\]

Substitution in the exact published formula for \(k\) proves (9), with a
constant depending only on the fixed balance constant. If \(m=N^a\), the
two exponents in (10) are

\[
a
\quad\text{and}\quad
\frac12-\frac{3a}{2},
\]

which meet at \(a=1/5\).

If a nonidentity local element has order greater than \(C\), no positive
exponent at most \(C\) annihilates it. The largest tested exponent is
\(m^2k\), which proves the sufficient direct condition (11). Equation (8)
then gives (12).

If every local order is \(T\)-rough, a \(T\)-smooth exponent is coprime to
it. The complete prefix \(1,\ldots,k\) is \(T\)-smooth exactly when the
largest prime \(P(k)\) is at most \(T\). Together with \(T\)-smooth \(m\),
this makes every \(m^2i\) coprime to every local order. Bertrand's postulate
gives a prime strictly between \(k/2\) and \(k\) for sufficiently large
\(k\), which proves (13).

## 4. Low/high fork

For each rational prime \(\beta\le B\), first compute \(\gcd(\beta,N)\).
A proper result factors. Otherwise run Lemma 2.1 through \(D\). It either
reports order above \(D\) or returns the exact global order \(m\le D\).

Factor \(m\) by trial division. For each prime \(r\mid m\), compute

\[
G_r=\gcd(\beta^{m/r}-1,N).
\]

The value \(N\) is impossible because \(m\) is the exact global order. A
proper value factors. If every \(G_r=1\), no hidden local order can lose an
\(r\)-primary part of \(m\); otherwise that local order would divide
\(m/r\). Hence both local orders equal \(m\). This is the published
local-order synchronization lemma.

Assume all scanned primes are synchronized low. Their public lcm \(M\)
divides both \(p-1\) and \(q-1\). The scan also proves \(p>B\), because the
prime \(p\) itself would otherwise have factored \(N\). Every \(B\)-smooth
integer \(x\le p\) is a nonzero product of scanned primes and satisfies

\[
x^M=1\pmod p.
\]

The polynomial \(X^M-1\) has at most \(M\) roots in \(\mathbb F_p\), so
\(\Psi(p,B)\le M\).

For example, take

\[
B=\exp((\log(n+2))^3).
\]

This is numerical QP and satisfies (14). Harvey--Hittmeir Lemma 2.4 gives

\[
\log\Psi(p,B)
\ge
\log p-\frac{\log p}{\log B}\log\log p.
\]

Since \(\log p=\Theta(n)\) on balanced inputs, the loss is
\(O(n/(\log n)^2)=o(n)\). This proves (16).

The congruences \(p,q\equiv1\pmod M\) and
\(\gcd(M,N)=1\) satisfy Gao--Feng--Hu--Pan Corollary 3.2 directly. Its cost
is QP by (16). No common-order witness is needed for this direct call.

The scan itself is numerical QP: it has at most \(B\) bases; every bounded
order search has numerical-QP cost; trial division of \(m\le D\) has
numerical-QP cost; and every synchronization screen uses polynomially many
modular powers and gcds.

The mixed branch is not resolved. Finally, reducing the displayed carry
identity modulo either hidden factor removes the carry and leaves the same
orbit generated by \(2\). This verifies only the named-interface statement.
