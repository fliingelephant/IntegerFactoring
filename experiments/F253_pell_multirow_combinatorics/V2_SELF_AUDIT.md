# F253 V2 self-audit

## Repair audit

1. V1 allowed \(k=1\). Then \(kj=j\), so its phrase "the two rows" did not
   define two columns, and the binary vector would be
   \(e_j+e_j=0\). V2 requires odd \(k>1\).
2. Even for \(k>1\), a finite bank need not contain index \(kj\). V2
   requires that both index-\(j\) and index-\(kj\) rows occur in the bank.
3. Canonical reduction can repeat a coordinate. V2 requires
   \(y_{kj}\ne y_j\) and requires both rows to survive cleanup. A repeated
   coordinate is tested and removed, not included in the pair set.
4. The clean polynomial identity remains valid without the presence,
   retention, or distinctness assumptions. V2 invokes those extra
   hypotheses only when it turns the identity into the nonzero binary
   vector \(e_j+e_{kj}\).
5. For every admitted pair vector, the exact product is square and its
   supplied root equals the positive root modulo \(N\). The P66
   normalized-root homomorphism is therefore \(+1\) on each generator and
   on their binary span. V2 makes no assertion about kernel vectors outside
   that span.

## Statement checks retained from V1

1. The rank theorem assumes no repeated coordinate within one \(D\) and no
   singleton square. Without the first condition, row multiplicity can
   violate the P214 coordinate count. With square rows retained, the
   displayed nonzero-class count needs a separate zero-class term.
2. Every positive integer square class has a squarefree positive integer
   representative. P214 applies with that fixed representative.
3. The nullity statement is an upper bound. P214 gives no positive lower
   bound on nullity and does not force a P66 relation.
4. The labelled-copy construction proves sharpness of the rank inequality
   from a fibre cap alone. It does not claim that a Pell bank realizes the
   construction.
5. The marked-subset estimate is valid but is not claimed optimal for each
   \(k\). In particular, a direct pair count can improve its \(k=2\)
   specialization.
6. The exact no-carry inequality \(F_{k,D}(y_j)<N\) is essential. A modular
   congruence alone does not give an integer square-class identity.
7. Retention is stated to include unit supplied roots. If a supplied root
   is nonunit, a gcd screen exits this branch before normalized-root
   division.
8. The carry equation does not say that a carried pair can never share a
   square class by another arithmetic coincidence. It isolates only the
   failure of the clean polynomial witness.

## Finite-computation checks

1. V1 and the computational V2 were separately preregistered before their
   runs. The computational V2 was designed after viewing V1.
2. The wrapper search_v2.py depends on an absolute temporary path. The
   exact bytes and hashes are preserved, and COMPUTATION.md gives the replay
   step.
3. The durable stdout files are post-run transcriptions. The displayed
   \(N=4331\) arithmetic is independently verified in V2_PROOF.md.
4. The frozen source did not reject the case \(\gcd(x,N)=N\). The V1
   hostile audit found this elsewhere in the scanned cohort. It also
   independently checked that every supplied root in the selected
   \(N=4331\) window is a unit, so the finite certificate is unaffected.
5. The selected relation has \(k=3>1\), both indices \(17,51\) in the
   frozen window, both rows retained, and distinct coordinates \(6,1746\).
   It therefore satisfies the repaired V2 hypotheses.
6. The finite certificate does not imply an asymptotic frequency, success
   probability, or factoring algorithm.

## Remaining gap

P214 controls the multiplicity of each exact square class. V2 removes the
subspace generated by distinct retained clean odd-multiple pairs by proving
that its normalized-root image is trivial. It does not control the quotient
kernel produced by canonical carries, other arithmetic specializations,
mixed discriminants, cross-family relations, absent or removed rows, or
other source structures.
