# F156 candidate — sparse section feedback is a deterministic quasipolynomial source

## Status and scope

This is a proof-only source-and-cost candidate. It adds one nonrecursive
decorated-section feedback layer to every frozen named-refinement stage of
P118. It remains deterministic quasipolynomial and can use dense
squareclass combinations that are outside the named-block support cap.

It is not an all-input success theorem or a factoring algorithm.

## Closest prior results and the material difference

P118 enumerates bounded-support words in the current named integer blocks.
P120 feeds powers of individual decoder blocks. P138 says that a failed
many-relation decoder is one consistent decorated section. F154 enumerates a
whole section when its dimension is polylogarithmic and proves that its
manufactured completion relations are decoder-inert, while their canonical
inverse representatives can still refine the named state.

F156 uses the section itself as a new candidate generator. It enumerates
polylogarithmic-support combinations of a relation basis, computes their
public decorated roots, and feeds those roots through canonical inversion.
A relation-basis word can represent a dense product of old integer blocks.
This is not the same source grammar as a bounded-support named-block word.

The section-generated relations are never used recursively as a later
section basis. This one-layer rule is the exact reason the full adaptive
source stays quasipolynomial.

## 1. Parameters and two ledgers

Put

\[
n=\lceil\log_2(N+1)\rceil,
\qquad
L=\lceil\log_2(n+1)\rceil,
\qquad
D=L^2,
\qquad
E=2^{L^2}.
\tag{1}
\]

Run the P118 adaptive named-refinement source with its seed bank, frozen
support-\(D\) and exponent-\(E\) word scans, endpoint exposure, and
descendant-only named-block update.

Maintain two relation ledgers.

1. The **base ledger** contains only canonical exact values generated by the
   P118 named-block word source.
2. The **feedback ledger** contains the extra canonical exact values
   generated below.

Both ledgers are retained for the final complete decoder. Only the base
ledger is allowed to generate the next section-feedback layer.

## 2. The frozen base section

At one frozen named stage, globally factor-free-refine the distinct base
exact values. After maximal perfect-power extraction, let
\(q_1,\ldots,q_m\) be the pairwise-coprime nonsquare unit blocks. Write each
base value as

\[
A_i=t_i^2Q(v_i),
\qquad
Q(v)=\prod_{j=1}^m q_j^{v_j},
\qquad
A_i\equiv1\pmod N.
\tag{2}
\]

Its supplied root is \(1\), so its decorated lift is

\[
g_i=(v_i,t_i^{-1})\in E_Q(N).
\tag{3}
\]

Before continuing, run the complete P138 online consistency test. If it
finds a non-global root, return its proper gcd factor.

Choose, in deterministic first-occurrence order, a binary parity basis

\[
b_1,\ldots,b_r
\tag{4}
\]

from the base records and retain the corresponding actual decorated lifts
\(e_1,\ldots,e_r\).

## 3. Sparse section candidates

For every nonempty set

\[
S\subseteq\{1,\ldots,r\},
\qquad
|S|\le D,
\tag{5}
\]

compute

\[
e_S=\mathop{\star}_{i\in S}e_i=(v_S,z_S),
\qquad
w_S=\iota_N(z_S).
\tag{6}
\]

Run the two direct screens

\[
\gcd(z_S-w_S,N),
\qquad
\gcd(z_S+w_S,N).
\tag{7}
\]

If either is proper, return it. Otherwise:

1. expose both integer endpoints \(z_S,w_S\) to the frozen batch;
2. retain the first exact canonical value

   \[
   F_S=z_Sw_S=1+\kappa_SN
   \tag{8}
   \]

   in the feedback ledger;
3. retain every endpoint presentation and source occurrence before
   exact-value deletion.

Scan the complete frozen base-section menu before applying a split.

The screen has the exact dense-squareclass form

\[
\boxed{
\gcd(z_S\pm w_S,N)
=
\gcd(Q(v_S)\pm1,N).
}
\tag{9}
\]

The right side can be evaluated through \(z_S^2\) modulo \(N\); the
possibly dense integer \(Q(v_S)\) need not be expanded for the gcd.

## 4. Named refinement and termination

After both the ordinary P118 word scan and the section-feedback scan are
complete, jointly refine all exposed endpoints with the frozen named basis.
Keep as future named generators only terminal factors that occur in an old
named block. Probe-only cofactors remain decoder data but never enter the
named grammar.

If an old named block splits, freeze the refined basis and start the next
stage. If no old named block splits, stop. Run one final complete
factor-free kernel and normalized-root decode on the union of the base and
feedback ledgers.

Feedback-ledger relations never enter a later section basis. Thus the source
has one decorated-section layer per named stage, not an uncontrolled
fixed-point recursion.

## 5. Deterministic quasipolynomial bound

The P118 initial named endpoint product has

\[
\Lambda_0=2^{O(L^2)}
\tag{10}
\]

bits. Every strict named stage splits a descendant of this fixed product, so
the number of named stages is at most \(2^{O(L^2)}\).

Across all stages, the base ledger has

\[
R_0=2^{O(L^4)}
\tag{11}
\]

records and total quasipolynomial bit length. Hence \(r\le R_0\), and one
section scan has at most

\[
\sum_{j=1}^{D}\binom rj
\le(D+1)\max\{1,r\}^{D}
=
2^{O(L^6)}
\tag{12}
\]

candidates.

Every new endpoint lies below \(N\), and every feedback exact value lies
below \(N^2\). The total source, endpoint batches, refinement work, storage,
and final decoder therefore have deterministic bit complexity

\[
\boxed{
2^{O((\log n)^6)}.
}
\tag{13}
\]

## 6. Strict relation to earlier grammars

A support-\(D\) named-block word uses at most \(D\) current integer blocks.
A support-\(D\) section word uses at most \(D\) retained relation-basis
vectors. Each such vector can itself be dense in the named blocks.
Therefore \(v_S\), \(Q(v_S)\), and \(z_S\) can have dense old-block
provenance even though (5) is sparse.

This is a syntactic source enlargement. It does not prove that a generated
residue is semantically absent from the full P118 residue set.

If the frozen base span has dimension at most \(D\), the scan enumerates the
entire actual lifted section and exposes every inverse representative used
by F154. Thus it captures the exact F154 refinement opportunity without
retaining the decoder-inert manufactured values \(P_v=s_v^2Q(v)\).

## 7. Exact remaining success gate

For a complete factoring result, one must prove that on every surviving
composite input this declared source causes at least one of:

1. a proper direct screen in (7);
2. a strict named refinement that later leads to a proper screen or useful
   relation;
3. a non-global normalized root in the final union decoder.

F156 proves only that this is one explicit, uniform,
quasipolynomially bounded gate. It gives no density, rank-defect, section
disagreement, or termination-to-factor law.
