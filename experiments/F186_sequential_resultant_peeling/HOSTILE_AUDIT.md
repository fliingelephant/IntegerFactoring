# Hostile audit of F186 — one-child sequential support peeling

## Verdict

**PASS.** The general one-child theorem is correct under its stated
support-cover hypothesis, and the P162/F185 cross-resultant list satisfies
that hypothesis in the double-extinction branch. Sequential powering selects
at most one smaller integer for recursive factorization. A one-bit decrease is
sufficient because the resulting recursion is a chain rather than a branching
tree.

This is only a postprocessor for double extinction. The wide-shift-hard
branch remains unresolved, so F186 is not an all-input factoring theorem.

## Attack 1: exact local-order evolution

Let

\[
E_i=\prod_{r=1}^i A_r^n.
\]

Skipping an entry equal to one does not change this product. Repeated
powering gives the public identity

\[
v_i=w^{E_i}\pmod N
\]

and therefore, in every hidden component,

\[
h_{j,i}=\operatorname{ord}_{R_j}(v_i)
=\frac{g_j}{\gcd(g_j,E_i)}.
\]

Thus later orders divide earlier orders. They remain coprime to the hidden
rational prime and, while nontrivial, remain \(T\)-rough. No step assumes
knowledge of a hidden order.

For \(R_j=p_j^{e_j}\), the reduction kernel

\[
(\mathbb Z/R_j\mathbb Z)^\times\longrightarrow
(\mathbb Z/p_j\mathbb Z)^\times
\]

is a \(p_j\)-group. Its intersection with the cyclic group generated by
\(v_i\), whose order is coprime to \(p_j\), is trivial. Hence

\[
v_i\equiv1\pmod {p_j}
\quad\Longleftrightarrow\quad
v_i\equiv1\pmod {R_j}.
\]

It follows that \(H_i=\gcd(v_i-1,N)\) contains either the entire hidden
prime power \(R_j\) or none of it. This proves the claimed \(1\), proper,
or \(N\) trichotomy for arbitrary prime powers. In particular, no partial
valuation can invalidate the first-global-return argument.

## Attack 2: support coverage supplies enough multiplicity

For \(\ell^a\parallel g_j\), one has

\[
\ell^a\le g_j<N<2^n,
\]

so \(a<n\). Coverage supplies an entry \(A_i\) divisible by \(\ell\).
Consequently

\[
v_\ell(A_i^n)\ge n>a.
\]

The full \(\ell\)-primary part of every local order is therefore removed by
the cumulative exponent. This argument needs only prime-support coverage;
the entries need not contain the original order valuations, be squarefree,
or be pairwise coprime. It gives

\[
g_j\mid E_B
\quad\text{and}\quad
H_B=N.
\]

An entry equal to one cannot cover a prime, so skipping such entries does not
affect eventual extinction.

## Attack 3: the first global return selects one annihilator

Initially \(H_0=1\): every \(g_j>1\), and the prime-power injectivity above
shows that \(w\) is nonidentity modulo every hidden rational prime. Suppose
no proper gcd has appeared, and let \(i\) be the first index with \(H_i=N\).
Every earlier identity gcd is then one, in particular

\[
H_{i-1}=1.
\]

Thus all current orders \(h_{j,i-1}\) are nontrivial. At the selected step,

\[
v_i=v_{i-1}^{A_i^n}=1\pmod {R_j}
\]

for every \(j\), and the elementary order criterion gives

\[
h_{j,i-1}\mid A_i^n
\qquad(1\le j\le s).
\]

This is stronger than cumulative coverage at precisely the needed point.
The proof does not incorrectly assert that \(A_i^n\) annihilates the
original \(w\). It annihilates the public current element \(v_{i-1}\),
which is sufficient for the returned common-order state.

Duplicate entries and overlapping prime supports cause no problem. They
only repeat primary deletion. Once a hidden component becomes the identity,
later powering cannot revive it.

## Attack 4: child selection and factor-first stripping

Before an entry is used, \(\gcd(A_i,N)\) is screened. A nontrivial gcd is a
proper factor because a used entry satisfies

\[
1<A_i<2^{n-1}\le N.
\]

On the surviving branch \(A_i\) is coprime to \(N\) and has at most
\(n-1\) bits. Strong induction can therefore return its complete
factorization, which gives a fully factored common multiple

\[
M=A_i^n
\]

of all current local orders.

The stripping argument is exact. With the current value of \(M\), a test

\[
D_r=\gcd(v_{i-1}^{M/r}-1,N)
\]

has these meanings:

- \(D_r=N\): every current local order divides \(M/r\), so deleting that
  copy preserves the common-multiple invariant;
- \(1<D_r<N\): the gcd is a certified proper factor;
- \(D_r=1\): no current local order divides \(M/r\), so every one has the
  full current \(r\)-adic valuation of \(M\).

If no factor occurs, applying this to every prime in the factored \(M\)
makes every local order equal the same final divisor \(m\). The public
element is \(v_{i-1}\), so this is a certified exact common-order state, not
only a numerical coincidence. Since its local orders were nontrivial and
\(T\)-rough, \(m>T\).

## Attack 5: one-bit child and total recursion cost

For the input-length convention

\[
n=\lceil\log_2(N+1)\rceil,
\]

the inequality \(\operatorname{bitlen}(A_i)\le n-1\) implies

\[
A_i\le2^{n-1}-1<N.
\]

There is exactly one recursive factoring call. All earlier entries need only
modular powering and gcds. If \(Q(n)\) is a nondecreasing numerical-QP
envelope for the local work, then

\[
\mathcal T(n)\le\mathcal T(n-1)+Q(n)
\]

unrolls to at most \(\mathcal T(n_0)+nQ(n)\), still numerical QP. This is
valid even when the selected child loses only one bit. It would not justify
several such children per parent; the statement explicitly excludes that
use.

Each explicit exponent \(A_i^n\) has \(O(n^2)\) bits. The QP list length,
modular powering, gcd screens, and at most \(O(n^2)\) prime-copy stripping
attempts fit inside the stated local envelope. For Las Vegas recursive
calls, the same recurrence holds in expectation, and the strictly decreasing
bit length gives finite recursion depth and almost-sure termination.

## Attack 6: inherited cross-resultant coverage

Double extinction is required for two filters evaluated on the same original
unit \(w\). Fix \(\ell\mid g_j\). The first extinction supplies
\(\delta\in\mathcal A\) and \(0\le k\le K\) with

\[
F_{\delta,k}(N)=0\pmod\ell.
\]

The second supplies \(\epsilon\in\mathcal B\) and \(0\le l\le K\) with

\[
F_{\epsilon,l}(N)=0\pmod\ell.
\]

Both polynomials are monic, including the index-zero linear case. Their
reductions are nonzero and have the common root \(N\bmod\ell\). Hence

\[
\ell\mid
\operatorname{Res}_X(F_{\delta,k},F_{\epsilon,l}).
\]

This proves the general theorem's support-cover premise. The separated
centres give \(3\le\epsilon-\delta\le2L+1\). The P162 unit-circle estimate
then gives a positive nonzero resultant and

\[
R<2^{K(1+K\lambda)}.
\]

Under \(K(1+K\lambda)\le n-1\), integrality yields
\(R\le2^{n-1}-1\), so every nonunit entry has at most \(n-1\) bits. There
are \(L^2(K+1)^2\) entries, and the imported P162/F185 parameter assumptions
make their construction QP.

The proof correctly retains the existing wide-shift-hard output when either
menu has identity gcd one. Sequential support peeling changes only the
double-extinction implementation.

## Scope

F186 removes the fixed-ratio, many-child recursion requirement from P162's
double-extinction branch. It does not prove that double extinction occurs,
resolve a wide-shift-hard descendant, construct a non-global root in that
branch, or yield a complete factoring algorithm. No computation, hidden
factorization, order oracle, smoothness assumption, or probability claim is
used.

The audit was symbolic. The only command-level computation was verification
of the supplied file hashes.
