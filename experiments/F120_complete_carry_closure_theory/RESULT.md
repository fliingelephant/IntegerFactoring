# F120 — A Universe-Private Row Refutes Forced REUSE

## Verdict

The complete word menu does **not** force `REUSE`.

There is a trial-hard odd distinct-semiprime input for which the seed-`2`
exact-value column has a valuation-one prime row that is private against
every possible canonical exact-value column, whether or not that column is
generated by F116. The counterexample is

```text
N = 2,000,887,089,301
  = 1,000,289 * 2,000,309,
r = (N+1)/2
  = 1,000,443,544,651 prime.
```

This is stronger than privacy inside a selected submatrix. It is finite. It
does not prove an infinite semiprime obstruction, `CLOSE`, or `ROOT`.

The exact reason is a new source-independent row-degree bound:

```text
degree(r) <= floor((N-1)/r).                              (1)
```

Thus every present odd-valuation row with `r>(N-1)/2` is private after global
exact-value deduplication.

No smoothness or random-matrix model is used.

## 1. Canonical inverse orbits

Let `1 <= c < N` be a unit, and let `w` be its least positive inverse. Write

```text
P_N(c) = c*w = 1 + kappa_N(c)*N.
```

The inverse map `c -> w` is an involution. It gives one unordered endpoint
orbit `{c,w}`. Its exact value is constant on that orbit.

If two distinct retained exact values use representatives `{c,w}` and
`{d,z}`, their endpoint orbits are disjoint. Indeed, any equality among an
endpoint of the first pair and an endpoint of the second pair identifies the
two inverse orbits and hence the two products.

Different inverse orbits can have the same product. Global exact-value
deduplication merges them. After that projection, one can choose one endpoint
orbit for each exact-value column, and the chosen orbits for distinct columns
are disjoint.

There is also a sharper carry bound than the full canonical interval gives:

```text
0 <= kappa_N(c) < min(c,w),
kappa_N(c) = -N^(-1) mod c, with 0 <= kappa_N(c) < c.     (2)
```

The inequality follows from `cw<cN` and `cw<wN`. The congruence follows from
`1+kappa_N(c)N=0 mod c`. For every nonunit exact value, the carry is nonzero.

## 2. Universe-level prime-row theorem

### Theorem

Let `C` be any set of distinct canonical exact values for one modulus `N`.
For any prime `r`, the number of columns in `C` having odd `r`-adic valuation
is at most

```text
floor((N-1)/r).
```

This bound is independent of the source, its order, and its size.

### Proof

Choose one inverse endpoint orbit `{c,w}` for each exact value. If `r` has
odd valuation in `cw`, at least one endpoint is a positive multiple of `r`
below `N`. Assign one such endpoint to the column.

Distinct exact-value columns have disjoint chosen inverse orbits. Therefore
their assigned endpoints are distinct. There are exactly
`floor((N-1)/r)` positive multiples of `r` below `N`. This proves (1).

### Stable-private corollary

If `r>(N-1)/2` occurs to odd valuation, equation (1) gives row degree at most
one. Since the row is present, its degree is exactly one. It is private among
all canonical exact values and remains private under every source extension.

This improves the carry-diameter threshold `r>N-3` from F119. The improvement
uses the fact that a prime divisor of `cw` must divide an endpoint, not only
the carry congruence.

## 3. An unconditional infinite odd-input family

Let `q` be any prime and set

```text
N = 2q-1.
```

The seed `c=2` has canonical inverse `w=q`, exact value

```text
P_N(2) = 2q = N+1,
kappa_N(2) = 1.
```

For `q>2`, its valuation at `q` is one and `q=(N+1)/2>(N-1)/2`.
The row is therefore private against the complete universe of exact-value
columns.

To keep both seed endpoint sign screens null, take primes
`q=1 mod 30`. Dirichlet gives infinitely many. Then

```text
gcd(2-q,N) = gcd(3,N) = 1,
gcd(2+q,N) = gcd(5,N) = 1.
```

This is an unconditional infinite odd-input source-law counterfamily to
universal `REUSE`. It does not ensure that `N` is composite, semiprime, or
trial-hard.

All three primality statements used proof-enabled Sage checks. The factors

factors also make it a non-perfect-power odd semiprime.

The seed `2` is the first source residue. Its inverse is `r`, its exact value
is `2r=N+1`, and `v_r(N+1)=1`. The input is coprime to `15`, so the two seed
sign gcds are one by the identities in section 3. The column is retained.

The universe-level theorem proves that no other exact-value column can have
an odd entry in row `r`. No full-source enumeration is needed for this
conclusion. Therefore this one input rigorously falsifies the statement that
every prime-row occurrence repeats on every trial-hard distinct semiprime.

The claim is about the exact-value projection used in the F116 corollary and
in F119. A raw residue matrix can contain both inverse representatives of one
exact value. Those duplicate columns differ by a global-root kernel direction
and are merged by the exact-value projection.

## 5. What this says about REUSE, CLOSE, and ROOT

### REUSE

Universal `REUSE` is false, even on the finite trial-hard semiprime above.
The complete all-pairs menu cannot reuse its row `r` because no canonical
exact-value extension can reuse it.

### CLOSE

No `CLOSE` conclusion follows. A private row forces its column coefficient to
zero in every dependency. Removing that row and column preserves the kernel
on all remaining coordinates. Repeating this operation is the usual
degree-one peel, and it preserves kernel nullity and every surviving support.

Thus the private seed column neither creates nor destroys a dependency among
the other columns. The finite falsifier can still have `CLOSE` elsewhere.
F120 did not enumerate or decode its remaining source.

### ROOT

No `ROOT` conclusion follows. On an odd distinct semiprime, define

```text
rho_N : ker(M_N) -> mu_2(N)/{+1,-1}
```

by sending a square dependency to its positive exact square root modulo `N`.
`ROOT` is the assertion that `rho_N` is nonzero. A nonzero kernel does not
force this homomorphism to be nonzero. Private-row peeling leaves `rho_N` on
the surviving kernel unchanged.

## 6. Exact remaining asymptotic lemmas

### One universe-private row on infinitely many live semiprimes

The present construction would become an infinite trial-hard semiprime
counterfamily to `REUSE` if one proved:

```text
There are infinitely many primes q such that
2q-1 = p*ell,
p and ell are distinct primes, and
min(p,ell) > bit_length(2q-1)^2.                          (SPS)
```

Condition `(SPS)` is the exact missing number-theory input for this route. It
was not proved or assumed here. The finite search supplies one instance only.

### A full all-column private-row obstruction

A stronger sufficient condition than F119 `(FSP)` is an infinite trial-hard
semiprime family satisfying

```text
for every k in K_N, some prime r>(N-1)/2 has
v_r(1+kN) odd.                                            (LFSP)
```

By the universe theorem, `(LFSP)` gives a stable private row in every complete
exact-value column. It forces full column rank and kernel zero. F120 proves no
such family. It controls only the seed-`2` column.

For a positive theorem, the required statements remain separate:

```text
rank_F2(M_N) < |K_N|,                                    (CLOSE)
rho_N is nonzero.                                         (ROOT)
```

The word menu alone has not been converted into either statement.
