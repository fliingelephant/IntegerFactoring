# F85 — one prime-saturation closure adds one canonical root coset

**Status:** proof-only candidate. No research computation was run. This is an
incremental factor-free decoder theorem, not a closure source or a factoring
algorithm.

## 1. Material difference

P74 proves that one binary square-class closure adds one canonical root coset
and that one induced-root test is complete after the old binary decoder
fails. F83 extends the static decoder to every public polynomial-size prime
but uses all basis vectors and all support-two combinations.

The present result gives the missing incremental form for every prime
\(\ell\). One appended relation either creates no new saturation vector or
adds one canonical coset of \(\ell\)-th roots. After the old decoder has
failed, at most \(\ell\) public mixed roots give a complete test of that
entire new coset.

## 2. Exact closure gate

Let \(N=pq\) for distinct odd primes. Let
\(q_1,\ldots,q_s\) be pairwise-coprime positive units modulo \(N\), and let

\[
A_i=\prod_{j=1}^s q_j^{e_{ji}}\equiv1\pmod N,
\qquad
1\le i\le m,
\]

be an explicit relation list with \(e_{ji}\in\mathbb Z_{\ge0}\). Fix a
public prime \(\ell\), let \(E\) be the
\(s\times m\) exponent matrix, and put

\[
V=\ker(E\bmod\ell).
\]

Append one relation

\[
A_*=\prod_{j=1}^s q_j^{b_j}\equiv1\pmod N
\]

with \(b_j\in\mathbb Z_{\ge0}\), after complete joint gcd-free refinement.
Refinement can duplicate or split
old block rows, but it preserves the old column kernel: every factor of one
old block inherits the same old exponent row. Work in the final refined
coordinates and write the new matrix as \([E\mid b]\).

### Theorem 1

If

\[
b\notin\operatorname{colspan}_{\mathbb F_\ell}(E),
\]

then

\[
\ker[E\mid b]=V\times\{0\}.
\]

If \(b\) is in the old column span, choose
\(c\in\mathbb F_\ell^m\) with

\[
Ec+b=0
\]

and put \(z=(c,1)\). Then

\[
\boxed{
\ker[E\mid b]
=(V\times\{0\})\oplus\langle z\rangle.
}
\tag{1}
\]

### Proof

For \((x,t)\) in the new kernel,

\[
Ex+tb=0.
\]

If \(t\ne0\), this equation puts \(b\) in the column span of \(E\).
Therefore a nonclosing column forces \(t=0\) and gives the first claim.

In the closing case, subtract \(tz\) from \((x,t)\). The last coordinate
becomes zero and the first \(m\) coordinates lie in \(V\). The sum in (1)
is direct because \(z\) has last coordinate one. \(\square\)

## 3. The canonical object is a root coset

For \(x\in V\), use canonical coordinate representatives and define the old
root residue

\[
R(x)
=
\left[
\prod_jq_j^{(\sum_i e_{ji}x_i)/\ell}
\right]_N.
\]

F83 proves that \(R\) is a homomorphism. Let

\[
H=R(V)
\le
\mu_\ell(\mathbb F_p)\times\mu_\ell(\mathbb F_q).
\]

In the closing case, take canonical representatives of \(c\) and define

\[
s_c
=
\left[
\prod_j
q_j^{(\sum_i e_{ji}c_i+b_j)/\ell}
\right]_N.
\tag{2}
\]

All exponents in (2) are nonnegative integers, and

\[
s_c^\ell\equiv A_*\prod_iA_i^{c_i}\equiv1\pmod N.
\]

The full new root image is

\[
\boxed{H'=\langle H,s_c\rangle.}
\tag{3}
\]

If \(c'\) is another solution, then \(c'-c\in V\), and homomorphism of the
root map gives

\[
s_{c'}H=s_cH.
\]

Thus, relative to the fixed block list and full integer exponent
presentation, the new canonical object is the coset

\[
\boxed{s_cH,}
\]

not a preferred induced root.

## 4. An \(\ell\)-element complete incremental decoder

Assume that the complete old F83 decoder has run and found no factor. Hence
the two old local identity kernels agree. The old root image \(H\) is then
either trivial or a one-dimensional graph with both coordinate projections
nontrivial.

Let \(b_1,\ldots,b_D\) be the public basis of \(V\), and compute every
public basis root \(R(b_i)\).

### Theorem 2

If every basis root equals one modulo \(N\), then \(H\) is trivial. In this
case the single test

\[
\gcd(s_c-1,N)
\]

is complete for all new roots in \(H'\).

Otherwise, choose any basis root

\[
h=R(b_i)\ne1\pmod N.
\]

Then \(H=\langle h\rangle\), and the public menu

\[
\boxed{
\mathcal T_c=\{s_ch^t:0\le t<\ell\}
}
\tag{4}
\]

is complete:

\[
H'\text{ contains an identity separator}
\iff
\exists y\in\mathcal T_c:
1<\gcd(y-1,N)<N.
\tag{5}
\]

If \(s_c\notin H\), exactly two elements of (4) are separators. If
\(s_c\in H\), none is.

### Proof

Each local group of \(\ell\)-th roots has order one or \(\ell\). After
hidden additive identifications, the old root map is a pair of linear
functionals. Failure of the complete old decoder says that their kernels
are equal. Therefore both are zero, giving \(H=1\), or both are nonzero and
proportional, giving a one-dimensional graph. A nonidentity basis root in
the second case is a nonzero vector in that line and generates \(H\).

If \(H=1\), the new image is generated by \(s_c\). If one coordinate of
\(s_c\) is the identity and the other is not, \(s_c\) itself separates. If
both are nonidentity, every nonzero power has two nonidentity coordinates;
if both are identity, the image is unchanged. The single test is complete.

Now let \(H=\langle h\rangle\) be a graph line. The menu (4) is exactly the
coset \(s_cH\). If \(s_c\in H\), the new image equals the old separator-free
image. If \(s_c\notin H\), then \(h,s_c\) are linearly independent and
generate the full two-dimensional local root product. Because both
coordinates of \(h\) are nonzero, there is a unique \(t\) that cancels the
first coordinate of \(s_ch^t\), and a unique \(t\) that cancels the second.
Independence makes these two values distinct. Exactly those two coset
elements are separators. This proves (5). \(\square\)

The argument includes \(\ell=2\). It reduces to the binary induced-root
coset behavior of P74.

## 5. Cost and consequence

For a numerically polynomial-size public prime \(\ell\), column-span testing,
one induced-root construction, and the at most \(\ell\) modular products and
gcds in (4) have deterministic polynomial bit complexity in the explicit
relation presentation and \(\log N\).

A public implementation first computes \(\gcd(\ell,N)\). If this is proper,
it already has a factor. Otherwise the saturation decoder proceeds. This
also makes explicit that the formal local case \(\ell=p\) or \(q\) is
algorithmically vacuous, although the theorem remains correct there.

This theorem changes the correct feedback decoder. One must not retain only
2-saturation or test only one induced odd-prime root. At every appended
relation, each relevant small prime has an exact closure gate. When the gate
opens, the complete new information is one root coset, and a short adaptive
coset scan is sufficient.

The source gap remains exact. The theorem gives no public law that makes a
feedback column close, makes \(s_cH\) leave the old graph, or selects a useful
prime \(\ell\) on every input. It proves no factoring algorithm or literature
novelty.
