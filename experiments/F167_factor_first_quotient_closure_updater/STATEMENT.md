# F167 candidate — factor-first quotient-closure updater

## Status and scope

This is a proof-only candidate. It combines two exact decoders for public
unit blocks released by canonical integer refinement.

1. One smooth absolute-order screen resolves every block whose order is
   supported by bounded prime powers in at least one hidden component.
2. A capped breadth-first search resolves the complete subgroup generated by
   all quotient fingerprints when that subgroup fits inside the cap.

The combined output is

\[
\boxed{
\text{factor}
\quad\lor\quad
\text{certified common-order state growth}
\quad\lor\quad
\text{a synchronized inert state}
\quad\lor\quad
\text{an explicit local-capacity lower bound}.}
\]

The result does not construct a useful released block. It does not prove that
the capacity branch is impossible. It is not an all-input source theorem or a
factoring algorithm.

## 1. Input state

Let \(N\ge3\) be odd. For the proof only, write its unknown prime-power CRT
decomposition as

\[
N=\prod_{j=1}^s R_j,
\qquad R_j=p_j^{\alpha_j},
\]

where the \(p_j\) are distinct odd primes. This decomposition is not input to
the algorithm.

Let \((g,M)\) be a public certified common-order state. Thus the complete
factorization of \(M\) is supplied,

\[
g^M=1\pmod N,
\]

and, for every prime \(\ell\mid M\),

\[
\gcd(g^{M/\ell}-1,N)=1.
\]

Hence

\[
\operatorname{ord}_{R_j}(g)=M
\qquad(1\le j\le s).
\]

Put

\[
H_j=\langle g\bmod R_j\rangle.
\]

Let \(d_1,\ldots,d_t\) be a frozen finite public list of units. Each block has
complete occurrence and word provenance. A gcd with \(N\) is taken before a
value enters the list, so a nonunit already gives a factor.

Let \(B\ge2\) be the absolute- and relative-order scan bound. Let \(C\ge1\)
be the quotient-closure cap. For a quasipolynomial application, \(B\), \(C\),
the block list, the known factorization of \(M\), and the full encoded
transcript all have quasipolynomial bit length in

\[
n=\lceil\log_2(N+1)\rceil.
\]

## 2. One absolute-order screen

Put

\[
\Lambda_B=\operatorname{lcm}(1,2,\ldots,B).
\]

Its complete factorization is public. For one released unit \(d\), define

\[
r_j=\operatorname{ord}_{R_j}(d)
\]

and compute

\[
A_d=\gcd(d^{\Lambda_B}-1,N).
\tag{1}
\]

For a positive integer \(r\), let

\[
\sigma(r)=\max_{\ell^a\parallel r}\ell^a,
\qquad \sigma(1)=1.
\]

Exactly one of the following occurs.

1. If \(1<A_d<N\), then \(A_d\) is a proper factor.
2. If \(A_d=1\), then

   \[
   \sigma(r_j)>B
   \qquad(1\le j\le s).
   \tag{2}
   \]

3. If \(A_d=N\), factor-first divisor stripping from \(\Lambda_B\) returns
   either a proper factor or one integer \(m\) such that

   \[
   \operatorname{ord}_{R_j}(d)=m
   \qquad(1\le j\le s).
   \tag{3}
   \]

On the no-factor branch of case 3, put

\[
L=\operatorname{lcm}(M,m),
\qquad e=L/M.
\tag{4}
\]

Local cyclicity gives

\[
\operatorname{ord}_{(\mathbb Z/R_j\mathbb Z)^\times/H_j}(dH_j)=e
\qquad(1\le j\le s).
\tag{5}
\]

Thus the F166 primary-component construction returns a public element of
exact common order \(L=Me\), or an intervening gcd returns a factor. Hidden
logarithm alignment is not needed for this state construction.

For the strongest factor-first version, also align \(d^e\) against \(g\).
The alignment either factors \(N\) or gives one exact global relation

\[
d^e=g^a\pmod N.
\tag{6}
\]

If \(L=M\), this proves global membership. If \(L>M\), it permits the
stronger F161 global subgroup compression.

### 2.1 The punctured bank is unnecessary in this strengthened decoder

If (1) is one, no local order divides \(\Lambda_B\), so no divisor of
\(\Lambda_B\) can make a local component return one. If (1) is proper, the
factor is already found. If (1) is \(N\), divisor stripping compares the
prime-power valuations of all local orders and factors at their first
disagreement. Therefore the remaining punctured-lcm exponents from P87 add
no outcome once factor-first exact-order reduction is applied to the global
return.

This is a decoder simplification. It does not make P87's original theorem
false.

## 3. The surviving absolute-plus-relative hard certificate

Only the branch \(A_d=1\) needs the bounded relative-order scan. For
\(e=1,2,\ldots,B\), in this order, compute

\[
D_e=\gcd(d^{eM}-1,N).
\tag{7}
\]

The F161 classification gives exactly one outcome.

1. A proper \(D_e\) factors \(N\).
2. A first global return \(D_e=N\) gives the same local relative order
   \(e\) in every component. F166 constructs a common-order state of order
   \(Me\); factor-first alignment can instead factor or give the exact
   relation required for global subgroup compression.
3. If every \(D_e=1\), then every local relative order exceeds \(B\).

Together with (2), the last branch gives the stronger public certificate

\[
\boxed{
\sigma(\operatorname{ord}_{R_j}(d))>B
\quad\text{and}\quad
\operatorname{ord}_{(\mathbb Z/R_j\mathbb Z)^\times/H_j}(dH_j)>B
\quad(1\le j\le s).}
\tag{8}
\]

Equation (8) is a retained hard block. It is not a factor and does not imply
that different retained blocks give independent quotient directions.

## 4. Capped quotient-fingerprint closure

The set-level updater starts from the entire frozen block list. Put

\[
K_j=\langle H_j,d_1,\ldots,d_t\rangle,
\qquad
Q_j=K_j/H_j.
\tag{9}
\]

For an exponent vector \(v\in\mathbb Z^t\), write

\[
d^v=\prod_{i=1}^t d_i^{v_i}\pmod N,
\qquad
f(v)=(d^v)^M\pmod N.
\tag{10}
\]

Let

\[
F=\langle d_1^M,\ldots,d_t^M\rangle
\le(\mathbb Z/N\mathbb Z)^\times.
\tag{11}
\]

Run a deterministic breadth-first search from \(1\), multiplying by the
listed fingerprint generators in frozen order. Store one full-provenance
word \(a_y\) with

\[
a_y^M=y
\]

for every stored fingerprint \(y\).

Before accepting or deleting a candidate \(y\), compare it with every
stored fingerprint \(z\) by

\[
G_{y,z}=\gcd(y-z,N).
\tag{12}
\]

This comparison continues even if \(y=z\pmod N\) for one stored value.
Another stored value can agree with \(y\) in only some hidden components and
therefore expose a factor.

Stop when a proper gcd appears, when the queue closes, or when \(C+1\)
globally distinct fingerprints have been stored.

### 4.1 Closed branch

Suppose the queue closes with

\[
\kappa=|F|\le C
\tag{13}
\]

and no factor occurred. Then, for every hidden component, projection is an
isomorphism

\[
F\xrightarrow{\sim}F_j,
\qquad
F_j=\langle d_1^M,\ldots,d_t^M\rangle\bmod R_j.
\tag{14}
\]

Also, the local map

\[
Q_j\longrightarrow F_j,
\qquad xH_j\longmapsto x^M
\tag{15}
\]

is an isomorphism. Hence

\[
\boxed{|Q_j|=\kappa\quad(1\le j\le s),}
\tag{16}
\]

and all groups in (14)--(16) are cyclic.

Factor \(\kappa\) by deterministic trial division. Since \(\kappa\le C\),
this has quasipolynomial cost under a quasipolynomial cap. Enumerate powers
inside the closed table and choose a public generator

\[
y=a^M
\]

of \(F\), retaining the word provenance of \(a\). Then

\[
\operatorname{ord}_{Q_j}(aH_j)=\kappa
\qquad(1\le j\le s).
\tag{17}
\]

Apply F166 to \((g,M)\), the word \(a\), and the common relative order
\(e=\kappa\). It returns a factor or a public common-order state of exact
order

\[
\boxed{M\kappa.}
\tag{18}
\]

If \(\kappa>1\), this is strict growth. If \(\kappa=1\), there is no order
growth. The latter case proves only local membership of every block in
\(H_j\); it does not prove global aligned membership.

### 4.2 Optional full relation recovery

The minimal F166 update in (18) need not preserve the complete global named
subgroup. A factor-first algorithm should retain all generators and their
provenance.

For a complete aligned presentation, first align \(a^\kappa\) against
\(g\). Next use the closed cyclic table to find \(c_i\) with

\[
d_i^M=(a^M)^{c_i}.
\]

Then align

\[
d_i a^{-c_i}
\]

against \(g\) for every \(i\). Each alignment either returns a proper factor
or one exact global relation. If all alignments succeed, the complete named
subgroup is the cyclic group \(\langle g,a\rangle\) of order \(M\kappa\),
and it can be compressed globally. This stronger output is required by an
F164-style relation lattice. It is not required only to obtain the next
common-order state.

### 4.3 Capacity branch

Suppose the search stores \(C+1\) globally distinct fingerprints without a
proper gcd. Then these values are distinct modulo every hidden component.
Consequently,

\[
\boxed{
|Q_j|\ge C+1,
\qquad
|K_j|\ge M(C+1)
\quad(1\le j\le s).}
\tag{19}
\]

This is a public common local-capacity lower bound. It is not a factor. It
does not show that different released blocks represent independent
directions.

## 5. State reset, provenance, and exact-value deletion

The fingerprint in (10) depends on the current common-order state. After any
strict state growth, all old fingerprints, closure tables, and quotient
capacities must be discarded and recomputed against the new \((g,M)\).
Global integer relations and generator provenance remain valid and must be
retained.

The block list must be frozen during one closure search. New blocks enter
only after that search ends.

Exact-value deletion in the square-class decoder is not sufficient for this
updater. Two equal exact relation values can have different canonical
endpoint factorizations. Deleting the later occurrence can delete the gcd
overlap that names a useful block. A compatible source therefore maintains
two ledgers.

1. A root-aware exact-value ledger deduplicates parity columns.
2. A presentation ledger retains every endpoint occurrence and its complete
   provenance, including occurrences whose exact product is a duplicate.

The presentation ledger uses a persistent gcd-free integer basis. When a
new endpoint splits an old block, it records the exact decomposition of the
old block and retains the old generator as historical provenance. Every new
terminal unit block is then eligible for the updater.

A cap on \(C\) alone is not enough. The complete encoded transcript must be
capped. It includes the generator list, all stored fingerprints, predecessor
words or exponent vectors, integer relations, block decompositions,
occurrence provenance, and every coefficient bit.

## 6. Quasipolynomial cost

The integer \(\Lambda_B\) has \(O(B\log B)\) bits. One absolute screen,
factor-first divisor stripping, one bounded relative scan, and every
factor-first alignment use quasipolynomial work when \(B\), the relevant
known prime factors, and the transcript are quasipolynomially bounded.

The direct closure implementation considers at most

\[
O(tC)
\]

generator edges and compares each candidate with at most \(C+1\) stored
values. It therefore uses

\[
O(tC^2)
\]

gcd comparisons, plus quasipolynomial modular arithmetic. A predecessor
table gives provenance words of length at most \(C\). Thus the closed and
capacity branches are deterministic quasipolynomial-time operations when
the full input and output encodings are quasipolynomial.

Every strict common-order update multiplies \(M\) by at least two, while
\(M\) remains below \(N\). Hence fewer than \(n\) strict updates can occur.
Resetting and rescanning a quasipolynomial block pool after each such update
therefore preserves quasipolynomial total cost.

## 7. Operational corollary for fixed-depth section feedback

Take any fixed-depth F165-style canonical section source whose complete
explicit transcript is quasipolynomial. Preserve its root-aware relation
ledger. In parallel, preserve every canonical endpoint pair in the
presentation ledger described in Section 5.

At the base and after each frozen feedback level:

1. complete the persistent gcd-free endpoint refinement;
2. freeze all newly named unit blocks and their provenance;
3. run the absolute-order screen and the relative scan on new blocks;
4. after each strict common-order growth, reset and rescan against the new
   state;
5. run the capped quotient-fingerprint closure on the full frozen block
   pool;
6. retain every factor, aligned relation, state-growth certificate, double-
   hard block from (8), or capacity certificate from (19).

For every fixed feedback depth, this complete workflow is
quasipolynomial. A clean finite capability experiment must fully saturate
the base workflow first. A later event counts as feedback-only only when its
successful endpoint or block first appears after the base transcript and an
N-only replay verifies the complete provenance chain.

This corollary proves cost and operational closure only. It gives no theorem
that a feedback level avoids the synchronized inert or capacity branches.

## 8. Relation to the closest results

- **P87.** P87's punctured bank detects bounded primary order mismatch. The
  exact-order reduction in Section 2 resolves the global-return branch too,
  so one \(\Lambda_B\) screen replaces that bank in this stronger decoder.
- **P92/P93.** These results power and enumerate a supplied subgroup to find
  a separator under structural promises. Section 4 instead enumerates the
  subgroup of quotient fingerprints and, on closure, lifts its generator to
  a larger common-order state.
- **F161/P148.** The one-generator case of Section 4 is a capped relative-
  order search. Section 2 also resolves bounded absolute primary order even
  when the relative order is larger than \(B\).
- **F164.** F164 gives capacity from any finite fingerprint bank and needs a
  rank-volume equality for global presentation closure. Section 4 chooses
  an adaptive bank that is the complete generated fingerprint subgroup when
  it fits under the cap. This makes the local quotient order exact. Optional
  alignment then supplies the full global relations.
- **F166/P150.** F166 is the final lift from one common relative-order word to
  a common-order state. Section 4 supplies that word and its exact relative
  order by public closure.

The direct obstruction remains the synchronized large cyclic quotient from
F164: its order can exceed the cap while every explored equality stays
global. P98 supplies actual stable semiprime families with arbitrarily large
powered local components and shows why large stable capacity is natural. It
does not, by itself, instantiate every hypothesis of the present
common-order quotient model. No stronger inference from P98 is made here.

## 9. Exact remaining problem

It remains to prove one of the following for a public quasipolynomial
canonical-feedback source on every surviving input:

1. a direct factor occurs;
2. an absolute- or relative-order branch closes;
3. the complete quotient fingerprint subgroup closes below a fixed
   quasipolynomial cap; or
4. repeated capacity certificates force a contradiction or a factor.

F167 proves the decoder and state transition under these events. It proves
no law that one of the useful events must occur.
