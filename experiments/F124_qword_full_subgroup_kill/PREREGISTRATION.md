# F124 preregistration

## Family and status

- Family: F26-Q.
- Run ID: F124-D01.
- Evidence class: finite kill test.
- A positive full-subgroup null refutes the universal static source claim on
  one input. A factor hit or a completed scan with no null is finite evidence
  only.

## Fixed corpus

Enumerate all ordered prime pairs \((p,q)\) in this fixed order:

1. \(257\le p<q\le4096\);
2. \(q\le2p\);
3. order by \((N,p,q)\), where \(N=pq\);
4. retain only pairs for which, with
   \(n=\lceil\log_2(N+1)\rceil\), both \(p>n^2\) and \(q>n^2\).

Primality and the displayed factorization are diagnostic input data. The
trial-hard condition prevents the declared \(n^2\) small-factor screen from
settling a retained input.

## Fixed initial source

For each retained input:

1. Process every seed \(2\le s\le n\) in increasing order.
2. Compute its least positive inverse \(w\bmod N\).
3. Run both direct screens \(\gcd(s-w,N)\) and \(\gcd(s+w,N)\).
4. Factor the integers \(s\) and \(w\) only for this diagnostic.
5. Let \(G_N\) be the sorted set of all rational prime divisors found.
6. Let \(\widehat H_N=\langle G_N\rangle\bmod N\).

The prime generators form a supergroup of the factor-free public block
subgroup. Therefore a null for the supergroup is also a null for F26-Q.

## Exact subgroup gate

Set

\[
R=2^{15}=32768.
\]

Compute \(|\widehat H_N|\) exactly from local discrete-log tables and the
index of the lattice generated by

\[
(p-1,0),\quad(0,q-1),\quad
(\log_{g_p}r,\log_{g_q}r)\quad(r\in G_N).
\]

The index is the gcd of all two-by-two minors. Hence

\[
|\widehat H_N|={(p-1)(q-1)\over\text{index}}.
\]

If the size is above \(R\), record the exact size and skip the input. If it
is at most \(R\), enumerate every subgroup residue and verify the size.

## Full processing

For each feasible subgroup:

1. Run both canonical inverse sign screens on every residue.
2. Retain one copy of each distinct exact integer \(P(c)=cw(c)\).
3. Factor each \(P(c)\) for the diagnostic parity matrix.
4. Use a sparse online binary decoder. Its dependent insertions form a
   kernel basis.
5. Compute the exact positive square root for every basis dependency.
6. Classify each root as global \(+1\), global \(-1\), or non-global modulo
   the displayed \(p,q\).

Stop the full corpus scan at the first feasible input that has no direct
factor and no non-global basis root. Preserve that input and its complete
certificate. Otherwise process the full fixed corpus.

## Deduplication rule

Deduplicate by the exact integer \(P\), not only by residue or inverse orbit.
Run direct screens before this deduplication. Duplicate copies of one exact
\(P\) add only the square \(P^2\), whose root is \(P\equiv1\pmod N\).

- Hard timeout: 1,800 seconds.
- Source: `scan_full_subgroup.py`.

- Log: `RUN.log`.
- Structured output: `OUTPUT.json`.
- Human result: `RESULT.md`.
- Failed runs: `FAILED_RUNS.md`.

The run must record corpus counts, exact subgroup sizes, generator hashes,
the first direct or relation witness for every feasible input, and the full
matrix/root summary for a decisive null.

## Falsifiers and limits

- Any mismatch between the lattice size and explicit subgroup enumeration
  invalidates the run.
- Any incorrect factorization or square-root reconstruction invalidates the
  run.
- A timeout supports no conclusion.
- A null for \(\widehat H_N\) closes the static source only. It does not close
  recursive feedback, unreduced integer products, or another decoder.
