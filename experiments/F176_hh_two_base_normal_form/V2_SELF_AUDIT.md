# F176 V2 candidate self-audit

## Central claim

F176 V2 reduces the F174 hard-source question to the literal integer two.
It uses the always-public exact state \((-1,2)\). A factored absolute
annihilator or bounded quotient return gives a factor or an exact common
state. The only unresolved output has large local primary order and large
relative order in every hidden component.

## Why V1 was replaced

V1 proved that a later HH escape was two or three. It retained a
prime-exponent Mersenne base-three branch and used a three-smooth collision
bank for larger escapes.

The stronger observation is earlier. If base two is processed exactly with
order at most \(n\), the input is exactly \(2^n-1\). A composite exponent
factors, while a prime exponent is odd and makes \(-2\) a common element of
order \(2n\). Thus the run never needs a later hard source. V1 and its
passing hostile audit remain frozen under the V1 filenames.

## Absolute-screen audit

- The factorization of \(\Lambda_n\) is public.
- \(r\mid\Lambda_n\) exactly when every primary component of \(r\) is at
  most \(n\).
- A global return supplies a legal factored annihilator.
- Factor-first stripping certifies exact equality in every hidden prime
  power, not only exact global order.
- A gcd-one absolute result forces a primary component above \(n\) in every
  hidden component.

## Mersenne and sign audit

- \(N\mid2^m-1\) with \(m\le n\) forces \(m=n\) and \(N=2^n-1\).
- A composite \(n\) gives the explicit factor \(2^{n/\ell}-1\).
- A surviving prime \(n\) is odd because \(N\) is composite.
- The direct order calculation for \(-2\) works in every odd prime-power
  component. It does not rely on P145's distinct-semiprime scope.
- Fermat's theorem gives \(\gcd(2n,N)=1\).

## Relative-screen audit

- The squaring kernel modulo every odd prime power is exactly
  \(\{1,-1\}\).
- A first global return makes every local quotient order equal to the same
  \(e\).
- The factored multiple \(2e\) supports exact divisor stripping.
- The public choice \(2\) or \(-2\) realizes the exact lcm order \(2e\).
- An all-one scan certifies quotient order above \(C\) in every component.

## Complexity and recursion audit

Every numerical cap is polynomial or QP in the input bit length. No
exponent has super-QP bit length. Trial division of \(e\le C\) is QP.

The complete recursion bound uses fewer than \(2n\) total factor-tree
nodes, not only a depth bound. Repeated prime factors do not change this
count.

## Scope risks retained

1. The hard base-two branch is not factored.
2. Absolute primary capacity is not an exact order.
3. Quotient capacity is not an exact quotient order.
4. No hidden-order localization theorem for \(N^k\pm1\) is assumed.
5. The theorem is not an all-input QP factoring algorithm.
