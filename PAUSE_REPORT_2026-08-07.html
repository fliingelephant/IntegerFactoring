Latest unfinished result: linked root choices

The latest candidate asked whether many linked two-way root choices create many independent chances to expose a factor. After safe simplification, one connected group has only one hidden two-way switch. More public polynomial equations then do one of three things: they accept both easy public choices; they expose a factor at once; or they ask for the hidden mixed choice, which is the original hard task.

The first audit found real scope errors. I corrected them. The fresh audit stopped when the goal was paused. Therefore, this result is a candidate, not a promoted result.

2 · Best current candidate

Sample a product that is zero.

Most promising clean target

Generate an almost-uniform random pair (a, b) such that a × b is zero modulo N.

For an odd composite number, at least one sample in three from the ideal distribution exposes a proper factor. A simple greatest common divisor calculation then reads the factor.

Known

If the sampler exists and is fast, the full factoring method follows.

→

Missing

Create that sample from bare N, without already knowing a factor.

Second candidate: combine many rare relations

Many individually rare relations can have a useful total success rate. This validates the basic idea of combining many chances. But the current exact evaluation needs about the fourth root of N steps. That is much too slow. The open question is whether one small summary can evaluate the whole pool at once.

3 · Lessons from past trials

The hard part is selection, not detection.

A final gcd is only a detector.

It can read a difference that already exists. It does not create the difference between the hidden prime parts.

More chances are not automatically better.

A large pool helps only when we can build and test the pool in time that grows slowly with the number of digits of N.

Public algebra often keeps both sides together.

The same public rule usually acts in the same way on both hidden prime parts. This keeps the useful mismatch out of reach.

A weak size or probability hint can still matter.

This path remains open. But the hint must be created from bare N, and a fast procedure must convert it into a factor.
