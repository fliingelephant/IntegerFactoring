## Frozen statement and implementation

The checked design is RETURN_MAP_JUMPS.md, SHA256
cbe3426744bb0d263a4439afdcd0847d7f1fe6992a18217914b2f857c970b8a8.
The checker is return_map_checks.py, SHA256
02e0717cf952f884e33c9457dc14752eb3a9863998a277a6a3146ce2b8b2649e.

For each generic case, the independent finite oracle directly sorts the
residues a*k mod N. It derives the successor and rank maps from that array.
It builds deleted visits by an incremental prefix and by direct arc counting.
The Euclidean floor-sum implementation is then checked against those direct
values. It is not compared with a second copy of the same formula.
