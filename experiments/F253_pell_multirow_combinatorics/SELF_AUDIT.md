# F253 self-audit

## Statement checks

1. The rank theorem assumes no repeated coordinate within one \(D\) and no
   singleton square. Without the first condition, row multiplicity can
   violate the P214 coordinate count. With square rows retained, the weaker
   bound is \(m\le B_\Sigma2^r\).
2. Every integer square class has a squarefree integer representative, so
   P214 applies with one fixed positive integer \(P\).
3. The nullity statement is an upper bound. P214 gives no positive lower
   bound on nullity and therefore does not force a P66 relation.
4. The labelled-copy sharpness construction is abstract. It proves only
   that the fibre premise cannot imply a stronger rank inequality.
5. The marked-subset argument counts all exact-square subsets, not only
   minimal circuits. The probability bounds are for uniform subsets. They
   are not a claim about the adaptive P66 basis or its utility.
6. The odd-multiple theorem requires odd \(k\). It requires the exact
   no-carry inequality \(F_{k,D}(y_j)<N\). A congruence alone is not enough.
7. The theorem says that the subspace generated by clean odd-multiple pairs
   has global root. It does not say that every dependency in the full bank
   is generated by those pairs.
8. If a supplied root is nonunit, a gcd already exits the clean branch.

## Computation checks

1. V1 and V2 were separately preregistered before their runs. V2 was
   designed after the V1 result and this adaptivity is explicit.
2. The V2 wrapper depends on an absolute temporary path. The exact source
   and hashes are preserved, and COMPUTATION.md gives the replay step.
3. The run did not save raw stdout itself. The durable stdout files are
   post-run transcriptions. The \(N=4331\) relation and global-root gcds are
   independently verified in PROOF.md.
4. The search factors rows by trial division. In the frozen range,
   \(N<500000\), so \(A<1+2N^2\) and \(\sqrt A<10^6\). The frozen prime
   table through one million is therefore sufficient for exact parity
   classes.
5. The claim of no earlier cleanup factor in the full \(N=4331\) window is
   supported by the deterministic source and output but has not received an
   independent hostile replay.
6. The finite certificate does not prove that carried dependencies are
   rare, frequent, or useful on larger inputs.

## Remaining mathematical gap

P214 controls the multiplicity of each exact square class. The odd-multiple
theorem removes one structured part of the kernel by proving its normalized
root globally trivial. Neither result controls the normalized-root image of
dependencies created by nonzero canonical carries, arithmetic
specialization, mixed discriminants, or other row families. That residual
multirow source problem remains open.
