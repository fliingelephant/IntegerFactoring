All seven claims hold, with exact uniform integer sampling implemented by a
Las Vegas rejection sampler of expected polynomial bit complexity.  As usual,
"inverse-polynomial probability" in Claim 7 means a uniform lower bound in
the input bit length.

## 1. Exact generation probability

Let

\[
H=\prod_{\ell\mid |H|}H_\ell
\]

be the Sylow decomposition.  The decomposition is a bijection of finite
sets.  Therefore a uniform element of \(H\) has mutually independent uniform
coordinates in the groups \(H_\ell\).  The same remains true for \(d\)
independent samples.  A list generates \(H\) if and only if its projection
generates every \(H_\ell\).  Thus the Sylow generation events are independent.

For a finite abelian \(\ell\)-group \(P\), a list generates \(P\) if and only
if its images generate \(P/\ell P\).  One direction is immediate.  For the
other, let \(K\) be the subgroup generated by the list.  Surjectivity on the
quotient says

\[
P=K+\ell P.
\]

Hence \(P/K=\ell(P/K)\).  Iterating this equality kills the finite
\(\ell\)-group \(P/K\), so \(P/K=0\) and \(K=P\).  This is the relevant
Frattini-quotient criterion.

The images of the samples in
\(P/\ell P\cong\mathbb F_\ell^{r_\ell}\) are independent and uniform.  They
span exactly when the linear map

\[
\mathbb F_\ell^d\longrightarrow\mathbb F_\ell^{r_\ell}
\]

whose columns are those images is surjective.  The proportion of full-row-rank
matrices is

\[
\frac{\prod_{i=0}^{r_\ell-1}(\ell^d-\ell^i)}
     {\ell^{d r_\ell}}
=\prod_{i=0}^{r_\ell-1}(1-\ell^{i-d}).
\]

If \(d<r_\ell\), the factor with \(i=d\) is zero, as it must be.  If
\(r_\ell=0\), the inner product is empty and equals one.  In particular, if
\(H\) is trivial, the outer product is empty, every list generates it, and
the probability is one.  Multiplying the independent Sylow probabilities
proves

\[
\Pr(\langle h_1,\ldots,h_d\rangle=H)
=\prod_{\ell\mid |H|}\prod_{i=0}^{r_\ell-1}
 (1-\ell^{i-d}).
\]

## 2. The positive universal constant

For every prime \(\ell\) and \(k\geq2\), one has
\(0<\ell^{-k}\leq1/4\).  Moreover,

\[
\sum_{\ell\ \mathrm{prime}}\sum_{k=2}^{\infty}\ell^{-k}
=\sum_\ell\frac{1}{\ell(\ell-1)}
\leq\sum_{m=2}^{\infty}\frac{1}{m(m-1)}=1.
\]

For \(0\leq x\leq1/4\),
\(-\log(1-x)\leq x/(1-x)\leq4x/3\).  The sum of the absolute logarithms of
the factors defining \(c_0\) is consequently finite.  No factor is zero, so
the infinite product converges to a strictly positive number.  Thus
\(c_0>0\).

The quotient \(H/\ell H\) has order \(\ell^{r_\ell}\), which divides
\(|H|\).  If \(|H|<2^n\), then

\[
2^{r_\ell}\leq \ell^{r_\ell}\leq |H|<2^n,
\]

so \(r_\ell\leq n-1\).  With \(d=n\), the local factor from Claim 1 is

\[
\prod_{i=0}^{r_\ell-1}(1-\ell^{i-n})
=\prod_{k=n-r_\ell+1}^{n}(1-\ell^{-k}).
\]

Its indices form a subset of \(\{2,3,\ldots\}\).  Deleting factors in
\((0,1)\) increases a product, so this local product is at least
\(\prod_{k=2}^{\infty}(1-\ell^{-k})\).  Multiplying first over the finitely
many primes dividing \(|H|\), then observing that adding the remaining prime
factors can only decrease the product, gives

\[
\Pr(n\text{ samples generate }H)\geq c_0.
\]

The same argument includes the trivial group: its generation probability is
one.

## 3. A factor-or-generate batch

Put \(G_N=(\mathbb Z/N\mathbb Z)^\times\), and let

\[
\alpha=\frac{\varphi(N)}{N-1}.
\]

Every sampled integer lies strictly between zero and \(N\).  Therefore, if
its gcd with \(N\) exceeds one, that gcd is automatically a proper factor.
The probability that all \(n\) samples are units is \(\alpha^n\).

Conditioned on all samples being units, their joint distribution is exactly
the product of \(n\) uniform distributions on \(G_N\).  Indeed, the original
joint distribution is uniform on \(\{1,\ldots,N-1\}^n\), and the conditioning
set is exactly \(G_N^n\).  This also proves conditional independence; no
approximation or unit-density assumption is used.

Because

\[
|G_N|=\varphi(N)\leq N-1<N+1\leq2^n,
\]

Claim 2 gives conditional generation probability at least \(c_0\).  Thus one
batch succeeds by finding a factor or by producing a generating list with
probability

\[
(1-\alpha^n)+\alpha^n c_0
=1-(1-c_0)\alpha^n
\geq c_0.
\]

Low unit density helps: it transfers probability to the factor branch.  The
algorithm does not have to distinguish a generating all-unit list from a
non-generating one.

Exact uniform sampling uses fair random bits as follows.  For \(M=N-1>1\),
set \(b=\lceil\log_2 M\rceil\), draw a uniform \(b\)-bit integer, and reject
it unless it is below \(M\); add one to an accepted value.  Its acceptance
probability exceeds \(1/2\), so it consumes fewer than two \(b\)-bit blocks
in expectation and is exactly uniform.  For \(M=1\), output one without
random bits.  The \(n=O(\log N)\) samples therefore use
\(O((\log N)^2)\) expected random bits.  Euclidean gcd tests and the output
list have polynomial bit complexity.  The exact sampler has unbounded
worst-case running time, as any fair-bit exact sampler for a general
non-power-of-two range must, but it is Las Vegas with expected polynomial
time.  This is the complexity notion used here and in Claim 7.

For \(N=2\), the only sample value is one and \(G_N\) is trivial, so the same
conclusion holds with probability one.

## 4. Three generators for an odd semiprime

For distinct odd primes \(p,q\), CRT gives

\[
G_{pq}\cong C_{p-1}\times C_{q-1}.
\]

Consequently \(r_\ell\leq2\) for every \(\ell\).  By Claim 1, three exact
uniform units generate with probability

\[
\prod_{\ell\mid(p-1)(q-1)}
\prod_{i=0}^{r_\ell-1}(1-\ell^{i-3}).
\]

For rank two the local product is
\((1-\ell^{-3})(1-\ell^{-2})\); for rank one it omits the second factor and
is larger.  Omitting primes also increases the product.  Hence the displayed
probability is at least

\[
\prod_{\ell\ \mathrm{prime}}(1-\ell^{-2})(1-\ell^{-3})
=\frac{1}{\zeta(2)\zeta(3)},
\]

using the Euler products, which converge for exponents two and three.

## 5. A factor-bearing unit for every composite

First let \(N=p^a\) with \(a\geq2\).  The canonical representative
\(x=1+p\) is a unit modulo \(N\), and

\[
\gcd(x-1,N)=p.
\]

This is nontrivial and proper.  It includes powers of two; for example, the
construction begins with \(x=3\) modulo \(4\).

Now suppose that \(N\) has at least two distinct prime divisors.  If \(N\) is
odd, choose one primary factor \(p_1^{a_1}\).  CRT supplies \(x\) satisfying

\[
x\equiv1\pmod{p_1^{a_1}},\qquad
x\equiv2\pmod{p_i^{a_i}}\quad(i>1).
\]

It is a unit and
\(\gcd(x-1,N)=p_1^{a_1}\), a proper nontrivial factor.

If \(N=2^aM\) with \(M>1\) odd, CRT instead supplies

\[
x\equiv1\pmod{2^a},\qquad
x\equiv2\pmod{p_i^{a_i}}
\]

for every odd primary factor.  Again \(x\) is a unit, and now
\(\gcd(x-1,N)=2^a\).  This handles the fact that every unit modulo two is
already congruent to one.  The cases exhaust all composite integers.

## 6. Meaning of later feedback

On the conditioning event, the sampled list generates \(G_N\) as an
abstract group.  Every later object certified to be a unit is an element of
\(G_N\), and is therefore already in the subgroup generated by the sampled
list.  The same statement applies pointwise if a feedback block contains
several units.  No later unit can enlarge that abstract subgroup.

This does not make feedback operationally redundant.  Abstract membership
only asserts that a word in the original generators exists.  It does not
provide that word, a preferred integer representative, or an explanation of
the relation that exposed the element.  Canonical feedback may supply any of
those forms of public access or provenance.  The claim correctly separates
information access from abstract subgroup enlargement.

## 7. Las Vegas promise reduction

Let \(m=\lceil\log_2(N+1)\rceil\).  Under the standard uniform meaning of the
promise, there is a polynomial \(Q\) such that, for every list generating
\(G_N\), the promised procedure returns a proper factor with probability at
least

\[
\varepsilon(m)=1/Q(m).
\]

Run a fresh batch from Claim 3.  Return any factor found by a gcd test.  If
all entries are units, run the promised procedure on the list and return its
factor if it succeeds; otherwise start a fresh iteration.

Let \(F\) be the event that the batch gcd tests find a factor, and let \(J\)
be the event that all entries are units and their list generates \(G_N\).
Claim 3 gives \(\Pr(F)+\Pr(J)\geq c_0\).  Averaging the procedure's guarantee
over all generating lists gives

\[
\Pr(\text{success in one iteration})
\geq \Pr(F)+\varepsilon(m)\Pr(J)
\geq \varepsilon(m)(\Pr(F)+\Pr(J))
\geq c_0\varepsilon(m),
\]

where \(\varepsilon(m)\leq1\) may be assumed.  Thus independent fresh
iterations have expected count at most \(Q(m)/c_0\).

Each batch has expected polynomial bit complexity, and the promised
procedure is polynomial-bounded on every list, including non-generating
ones.  Every returned answer is checked to be a proper divisor, so an
iteration can return a correct factor or continue, but can never return an
incorrect factor.  The resulting algorithm is therefore Las Vegas and has
expected polynomial running time on composite inputs.  A primality test can
handle prime inputs; recursive use on the resulting factors gives full
factorization with only polynomially many subproblems.

## Scope

The result supplies a constant-probability source of full unit-group
generating lists, with a factor as the alternative outcome, and proves the
stated promise reduction.  It does not construct a localizer, show that a
special directly sampled subset has useful density, compute element orders,
solve a classical hidden-subgroup problem, or factor integers without the
additional promised procedure.
