# F236 follow-up preregistration: carry/residual tradeoff

Use the same complete finite domain and centered carry definition as the
earlier F236 preregistrations.  For each pair compute

\[
T=\min(c,s_p,s_q).
\]

Freeze these outputs:

- the maximum `T` and all record-setting pairs;
- the maximum `T` by input bit length;
- the ten largest `T`, with `e,D,s_p,s_q,c`;
- the same maxima restricted to `e=1,D=1` and to prime `s_p,s_q`.

This tests the possible dichotomy "enumerate a small centered carry or use
an already small P204 residual."  It is evidence only.
