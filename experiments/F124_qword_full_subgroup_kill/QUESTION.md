# F124 — full-subgroup kill for F26-Q

Can the complete static F26-Q word source fail even when it is enlarged to
the full residue subgroup generated by every prime divisor of its initial
seed endpoints?

For an odd semiprime (N), let the initial endpoints be

\[
\{s,s^{-1}_{\rm can}:2\le s\le n\},
\qquad n=\lceil\log_2(N+1)\rceil.
\]

Let \(\widehat H_N\) be the subgroup of \((\mathbb Z/N\mathbb Z)^\times\)
generated by every rational prime divisor of these endpoints. This is a
factor-assisted supergroup of the public F26-Q block subgroup.

For every \(c\in\widehat H_N\), put

\[
w(c)=c^{-1}_{\rm can},
\qquad
P(c)=c w(c).
\]

The decisive outcome is an input for which both conditions hold:

1. all \(\gcd(c-w(c),N)\) and \(\gcd(c+w(c),N)\) are trivial;
2. the complete P66 decoder on all distinct \(P(c)\) has only global roots.

Such an input is an exact counterexample to the universal static F26-Q
source claim. Every declared sparse word lies in \(\widehat H_N\), and every
dependency of a subsource is also a dependency of the full set.

This experiment does not test blocks created by later feedback.
