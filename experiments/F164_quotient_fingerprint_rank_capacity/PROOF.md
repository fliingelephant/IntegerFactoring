# Proof of the F164 quotient-fingerprint rank–capacity updater

## 1. The fingerprint kernel

Fix one hidden prime-power component `R_j`. Its unit group is cyclic. The
F161 certificate gives an element `g_j` of exact order `M`, so `M` divides
the component group order. In a cyclic group, the kernel of the `M`-th
power map has size `gcd(M,|G_j|)=M`. It is therefore the unique subgroup of
order `M`, namely `H_j=<g_j>`.

For public words `d^u,d^v`, commutativity gives

\[
F(u)F(v)^{-1}=(d^{u-v})^M.
\]

Hence `F(u)=F(v) mod R_j` if and only if `d^(u-v)` belongs to `H_j`. This
proves equation (2).

## 2. Pairwise factor-first comparison

For two integer fingerprints, let

\[
G=\gcd(F(u)-F(v),N).
\]

If `G` is proper, it is already a verified factor. If `G=1`, the
fingerprints are different even modulo every hidden prime and therefore
different modulo every `R_j`. If `G=N`, they are equal modulo `N` and hence
equal modulo every `R_j`.

Thus, on the no-factor branch, exact equality modulo `N` induces the same
equivalence relation on `S` as quotient-coset equality in every hidden
component. After exact deduplication there are `kappa(S)` represented cosets
in every component. The subgroup generated by `H_j` and the released blocks
contains these cosets, each of size `M`. This proves (5). Nested banks give
nested represented-coset sets, so the count is monotone.

## 3. Layer scan and collision alignment

Multiplication by `d^(eM)` is a bijection modulo every component. Therefore
the fingerprints inside `T_e` have the same pairwise equality and gcd
pattern as those in `T`. Each layer contains exactly `kappa` local quotient
cosets on the no-factor branch.

Suppose `e` is the first layer with a common collision against an earlier
layer. All layers `T_0,...,T_(e-1)` are pairwise disjoint, so retaining them
gives exactly `e*kappa` quotient cosets in every component.

For a collision `F(d^e w)=F(d^f w')`, put

\[
x=d^{e-f}ww'^{-1}.
\]

The fingerprint equality says `x^M=1 mod N`. Thus `x` lies in `H_j` in
every hidden component. The factor-first Pohlig--Hellman routine proved in
F161 compares the local base-`ell` digits of the logarithm of `x` to base
`g`, for every prime power dividing `M`. A digit mismatch gives a proper
gcd. If there is no mismatch, all local logarithms align to one public
`a mod M`, and `x=g^a mod N`. This proves (9).

Every old relation vector has zero in the coordinate of the newly
introduced block. The new vector has coefficient `e-f`, with
`1<=e-f<=B`. It cannot lie in the rational span of the old rows. Hence the
known relation rank increases by one.

If no layer through `B` collides, all `B+1` layers are disjoint in every
component, and the represented-coset count is exactly `(B+1)kappa`. This
proves all layer outcomes.

## 4. Rank–capacity inequality

Start with no released-block coordinate, no collision row, and bank `{1}`.
For each introduced coordinate, there are two accounting cases.

- A first common collision adds one independent relation row. It multiplies
  the retained bank by `e>=1`.
- No collision adds no relation row. It multiplies the retained bank by
  `B+1`.

After `t` calls with `r` selected collision rows, exactly `delta=t-r` calls
were no-collision calls. Ignoring all factors `e>=1` from collision calls
gives

\[
\kappa\ge(B+1)^{t-r}.
\]

This proves (10). The statement is about the selected triangular history.
Extra collision rows can only strengthen the retained relation lattice.

## 5. Rank–volume closure

Use the word homomorphism

\[
\Psi_j:\mathbf Z^{t+1}\longrightarrow
(\mathbf Z/R_j\mathbf Z)^\times,
\qquad
(z,v)\longmapsto g^z d^v.
\]

Every retained row is an exact global relation, so

\[
L\subseteq\ker\Psi_j
\]

for every `j`. If `L` has full rank, the finite presentation

\[
P=\mathbf Z^{t+1}/L
\]

has order `D`. It maps surjectively to

\[
A_j=\langle g,d_1,\ldots,d_t\rangle_{R_j},
\]

so `|A_j|<=D`.

The element `g_j` supplies a subgroup `H_j` of order `M`. The fingerprint
bank supplies `kappa(S)` distinct cosets of `H_j` inside `A_j`. Therefore
`|A_j|>=M*kappa(S)`. This proves (12).

If `D=M*kappa(S)`, both bounds are equal. Every surjection `P->A_j` is then
an isomorphism. The group `A_j` is a subgroup of the cyclic component unit
group, so it is cyclic. Hence `P` is cyclic. Its Smith form is

\[
\operatorname{diag}(1,\ldots,1,D).
\]

The associated unimodular column transformation gives an exponent vector
whose class generates `P`. Its public word `h` maps to a generator of every
`A_j`. The global CRT map has trivial kernel because each component map is
injective. Thus `h` also has exact global order `D`.

The screen `gcd(D,N)` either gives a factor or proves the coprimality needed
by the next F161 state. Under the equality `D=M*kappa`, only `kappa` needs
new factorization. If the explicit bank is bounded by
`2^((log n)^O(1))`, trial division through `sqrt(kappa)` is
quasipolynomial. Merging with the supplied factorization of `M` gives the
complete factorization of `D`.

If the bounds do not meet, `P` can be a proper cover of every `A_j`. Smith
rank alone cannot identify the hidden kernel index. This is the finite form
of the P71 order boundary.

## 6. The exact finite obstruction

For `N=341`, the displayed canonical-inverse products are exact:

\[
337\cdot85=28645=1+84\cdot341,
\]

\[
325\cdot277=90025=1+264\cdot341.
\]

Their complete joint gcd-free refinement contains `337` and `277` as
coprime unit blocks. Put `g=340=-1` and `M=2`.

Modulo `11`, the least powers of `337=-4` and `277=2` that enter
`{+1,-1}` are both fifth powers. Modulo `31`, they are respectively `-4`
and `-2`; their least powers in `{+1,-1}` are again fifth powers. Hence
both local relative-order pairs are `(5,5)`, which is beyond `B=2`.

Direct integer arithmetic gives

\[
277\cdot337^2
\equiv (-64)(-4)^2
=-1024
\equiv-1
\pmod {341}.
\]

Thus the second block lies in the subgroup generated by the first block
and `g`. The relation is globally aligned, so its Pohlig--Hellman check
does not factor. With the first bank `{1,d_1,d_1^2}`, the quotient cosets
have exponents `{0,1,2}` in a group of order five. Multiplication by `d_2`
shifts them by three, and the shifted layer meets the old layer at zero.
The bank therefore produces an aligned relation, not a second forced
capacity multiplier.

This example uses legal canonical-inverse relations and joint gcd-free
refinement. It shows that integer coprimality and exact provenance do not
imply quotient independence.

## 7. General cyclic countermodel

Let both hidden quotient images contain a cyclic group `C_R` of prime order
`R>B`. Identify the two copies by any automorphism. Map every public
released block `d_i` to a nonzero power of one common generator, using the
same exponent after that identification.

Each individual block has local relative order `R`. For every exponent
word, membership in the old subgroup is the same linear congruence modulo
`R` in both hidden components. Therefore every quotient collision is
synchronized: the gcd tests are only `1` or `N`. Choose the old-subgroup
coordinates of the blocks from one global presentation. Then every
collision logarithm also aligns, so the factor-first alignment never
separates the components.

All blocks together still generate only `C_R`. Naming more blocks cannot
give a product lower bound. Finite relations can express the added blocks
as powers of one unresolved direction, but the remaining relation is its
order `R`. Recovering it is exactly a one-generator order problem of the
type isolated by P71.

## 8. Cost and exact limit

For a bank of size `K`, one layer call creates at most `(B+1)K`
fingerprints and uses at most their squared number of gcd comparisons. A
square of a quasipolynomial is quasipolynomial. Factor-first alignment is
quasipolynomial by F161. HNF and SNF are polynomial in their explicit
matrix dimensions and bit lengths, so they remain quasipolynomial for an
explicit quasipolynomial transcript.

The proof supplies no compressed representation once the explicit bank
exceeds the allowed size. It also supplies no law forcing enough collisions
for `D=M*kappa`, and no law forcing disjoint layers against the subgroup
generated by all earlier blocks. Those are source-side requirements, not
decoder consequences.
