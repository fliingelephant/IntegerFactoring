## Verdict

**FAIL as frozen.** The local-orbit theorem, Cohen--Lenstra compatibility
attribution, generalized-CRT residue composition, fixed-bank obstruction,
generic probability bounds, primary-2 formulas, and concrete witness all
survive hostile reconstruction.

The blocker is narrower. Theorem C claims numerical-QP bit complexity, but
it bounds the encodings of `S` and the exponents `i` only. It does not bound
`tau`, require a canonical QP-size encoding of `b`, or give the immediate
large-`tau` exit. Consequently, the proof's sentence that the explicit
encoding hypotheses make every generalized-CRT operation numerical QP is
false as written. The algebraic terminal is correct. The bit-complexity
proof needs one extra premise or one extra branch.

There is also a nonblocking omitted case in the proof of Theorem D. When
`R=1`, the proof calls the odd obstruction empty but does not prove the
preceding assertion that every sufficiently large `(X,2X)` contains two
primes. The ordinary prime number theorem supplies that assertion
immediately.

## 1. Blocking bit-complexity gap in Theorem C

The algebraic argument gives

\[
L_0=\operatorname{lcm}(2^\tau,M),
\qquad
L=\operatorname{lcm}(L_0,S),
\]

and correctly retains a branch satisfying `p = s_i mod L`. However, the
only explicit size premise is:

> The values `S` and `i` are explicitly encoded with numerical-QP bit
> length.

There is no corresponding premise for `tau`, `b`, `2^tau`, `L_0`, or `L`.
The proof nevertheless says that the explicit encoding hypotheses make
every generalized CRT and gcd screen numerical QP.

This does not follow. For example, take any promised balanced semiprime,
put

\[
M=1,\qquad S=1,\qquad I=\{0\},\qquad \tau=2^n,
\]

and use the canonical low residue `b=p`. All displayed hypotheses hold,
including (C5) modulo `S=1`, and (C9) holds by an enormous margin. But

\[
L=2^{2^n}
\]

has `2^n+1` bits. This is not
`2^{(log n)^{O(1)}}`. An ordinary explicit generalized-CRT computation
modulo `L` is therefore not numerical QP.

This example does not refute the underlying conditional factorization
claim: with a canonical residue, `tau >= n` implies

\[
0<p<N<2^n\le 2^\tau,
\]

so `b=p` and `gcd(b,N)` returns the factor immediately. That is the missing
branch, not the branch proved in the frozen text.

Either of these repairs is sufficient:

1. require `0 <= b < 2^tau` and `1 <= tau <= n`; or
2. require the canonical residue, first return `gcd(b,N)` when `tau >= n`,
   and run the written CRT argument only when `tau < n`.

The second repair preserves the intended theorem without restricting useful
data. It is not present in the frozen proof. Thus the exact numerical-QP
claim does not pass.

The rest of Theorem C is sound. The true factor proves generalized-CRT
compatibility. A prime common to `M` and `N` would divide its own
predecessor, so `gcd(L,N)=1`. A complete gcd-screen pass must occur before
GFHP calls: if `L>p`, the true canonical residue equals `p` and that pass
already factors `N`; otherwise `L<p<N`, and every GFHP call has a valid
modulus smaller than `N`. At the true retained exponent, GFHP Theorem 3.1
with `r=1`, `m=L`, and `s=s_i` returns `p` in

\[
O\!\left(
\left\lceil\frac{N^{1/4}}L\right\rceil
\log^{7+3\epsilon}N
\right)
\]

bit operations. Condition (C9) makes this numerical QP once the input-size
gap above is repaired.

## 2. Theorem A: local orbit and cross-prime compatibility

**PASS.** The full character group separates points of the cyclic group
`(Z/qZ)^*`. Hence one common exponent for all characters is equivalent to
`r` belonging to the orbit generated by `N`. The complete exponent set is
one class modulo `ord_q(N)`. Pairwise agreement modulo the gcds of the
orders is exactly the generalized-CRT solvability criterion.

Allowing a different exponent for each character or each auxiliary prime
would break the conclusion. The theorem does not make either quantifier
error.

## 3. Theorem B: Cohen--Lenstra attribution

**PASS.** I inspected the primary Cohen--Lenstra paper, [*Primality testing
and Jacobi sums*](https://doi.org/10.1090/S0025-5718-1984-0726006-X),
especially condition (6.4), Theorems 6.3 and 7.8, and algorithms 11.1 and
12.1.

Condition (6.4) attaches `l_p(r)` to the primary prime `p` and divisor `r`,
not to an individual auxiliary prime or character. Theorem 7.8 uses that
same value to prove condition (6.5),

\[
\chi(r)=\chi(N)^{l_p(r)}.
\]

The chosen primary characters generate the full character group at each
auxiliary prime. Theorem 6.3 combines the primary exponents and concludes
that each divisor is congruent to one of `N^0,...,N^(t-1)` modulo the
auxiliary modulus. This is exactly the compatibility mechanism claimed in
F223.

The source also supports the failure semantics. A failed Jacobi-sum test
declares the input composite; it does not generally return a rational
factor. Final trial division occurs only after the orbit conclusion.

I also inspected the primary APR scan, [*On distinguishing prime numbers
from composite numbers*](https://math.dartmouth.edu/~carlp/PDF/paper37.pdf),
Section 4. Equations (4.5)--(4.6) and steps C.1--C.4 have the consolidation
geometry stated in F223. Remark 4.1 explicitly distinguishes composites
factored in consolidation from composites rejected earlier.

## 4. Theorem D: fixed-bank obstruction

**PASS, with the `R=1` proof omission noted above.** For fixed `R>1`, the
class `-1 mod R` is reduced. The prime number theorem in that fixed
arithmetic progression gives more than two primes in every sufficiently
large dyadic interval. Choosing two gives

\[
u<v<2u,
\qquad
u\equiv v\equiv-1\pmod q,
\qquad
N\equiv1\pmod q
\]

for every odd bank prime. Thus the orbit is `{1}` while each hidden residue
is `-1`. The quantifiers are correct: the bank and hence `R` are fixed before
the factors are chosen. Nothing here covers an `N`-dependent or refreshed
bank.

For `R=1`, the same conclusion about two primes follows from the ordinary
prime number theorem. The frozen proof should say this instead of stopping
after calling the odd obstruction empty.

## 5. Theorem E: generic independent-residue tail

**PASS.** For fixed `i`, each target `a_q^i` is one unit among `q-1`, so the
Bernoulli parameter is exactly `1/(q-1)`. Independence across `q` gives the
displayed moment product. Chernoff--Markov yields (E3) and (E5). Applying it
to

\[
W_i=\log P_i
\]

correctly produces `q^lambda`, not `e^lambda`, in (E7). A union bound over
candidate exponents needs no cross-exponent independence.

The theorem is explicitly a probability model. It proves no distribution
law for the residues of factors of a fixed integer. The packet does not use
it as one.

## 6. Theorem F: primary-2 return and sign laws

**PASS.** In a cyclic group of order `u-1`, the `E`-power map has a kernel
of size `g_u=gcd(E,u-1)`. The `-1` fibre exists exactly when
`g_u | (u-1)/2`, and then has the same size. The `+1` and `-1` fibres are
disjoint. CRT makes the two local components independent, so the union and
exclusive-or formulas (F5)--(F6) are exact.

Also,

\[
g_u\mid\gcd(N-1,u-1)=\gcd(v-1,u-1)=d,
\]

and symmetrically for `g_v`, while `d | v-u`. The bounded-gap sign-gate
union bound and its `2^{-n/2+O_H(1)}` balanced form follow. The packet uses
`g_u=g_v=d` only under an additional premise.

As a check, I exhaustively evaluated all 78 prime pairs
`3 <= u < v <= 43`, enumerated every unit modulo `uv`, and compared the
return, exclusive-or, sign-fibre, and divisibility counts with (F4)--(F9).
Every count matched. This finite check supports the reconstruction; it is
not used as proof.
