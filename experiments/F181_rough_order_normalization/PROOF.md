# Proof of the F181 rough-order normalization

## 1. Exact primary deletion

Fix a hidden component \(R_j\) and a prime power
\(\ell^a\parallel f_j\). Since

\[
\ell^a\le f_j<N<2^n,
\]

one has \(a<n\).

If \(\ell\le T\), then \(\ell\mid\Lambda_T\). Therefore

\[
v_\ell(Q)=n\,v_\ell(\Lambda_T)\ge n>a.
\tag{1}
\]

Raising \(y\) to \(Q\) deletes the complete \(\ell^a\) part of its local
order. If \(\ell>T\), then \(\ell\nmid\Lambda_T\), so raising to \(Q\)
preserves the complete \(\ell^a\) part. The standard order-of-a-power
formula

\[
\operatorname{ord}(y^Q)
=\frac{\operatorname{ord}(y)}{\gcd(\operatorname{ord}(y),Q)}
\tag{2}
\]

now gives

\[
\operatorname{ord}_{R_j}(w)
=\prod_{\substack{\ell^a\parallel f_j\\ \ell>T}}\ell^a
=g_j.
\tag{3}
\]

This proves the exact filter formula.

## 2. Meaning of the gcd screen

The order \(g_j\) is coprime to the rational prime below \(R_j\), because
it divides \(f_j\) and \(\gcd(f_j,N)=1\). Reduction from
\((\mathbb Z/R_j\mathbb Z)^\times\) to the corresponding prime field has a
prime-power kernel. It is therefore injective on the subgroup generated by
\(w\). Consequently,

\[
w\equiv1\pmod {p_j}
\quad\Longleftrightarrow\quad
w\equiv1\pmod {R_j}
\quad\Longleftrightarrow\quad
g_j=1.
\tag{4}
\]

Thus a proper value of \(H\) is a proper factor. The equality \(H=1\)
means \(g_j>1\) for every hidden component. Every prime divisor of \(g_j\)
is above \(T\), so

\[
g_j\ge P^-(g_j)>T.
\tag{5}
\]

The coprimality with \(N\) is inherited from \(f_j\). This proves the rough
branch (9) of the statement for arbitrary prime powers.

## 3. The global-identity branch and factor-first stripping

Suppose \(H=N\). Equation (4) gives \(g_j=1\) for every \(j\). Hence every
prime divisor of every \(f_j\) is at most \(T\). Equation (1), applied to
each primary part of \(f_j\), shows

\[
f_j\mid Q
\qquad(1\le j\le s).
\tag{6}
\]

The complete prime factorization of \(Q\) is public. Start with \(m=Q\).
For each prime \(r\mid m\), repeatedly compute

\[
D_r=\gcd(y^{m/r}-1,N).
\tag{7}
\]

If \(D_r=N\), replace \(m\) by \(m/r\). If \(1<D_r<N\), return the
factor. If \(D_r=1\), retain that copy of \(r\) and continue with the other
prime divisors.

Assume no proper gcd occurs. At termination, fix \(r\mid m\). The last
test for this \(r\) returned one, so no hidden local order divides \(m/r\).
Every local order does divide \(m\). Therefore every \(f_j\) has the full
\(r\)-adic valuation of \(m\). This holds for every prime divisor of \(m\),
and hence

\[
f_j=m
\qquad(1\le j\le s).
\tag{8}
\]

This is one exact common local order. The P160 premise
\(\sigma(f_j)>T\) gives

\[
m=f_j\ge\sigma(f_j)>T.
\tag{9}
\]

This verifies both the factor-first interface and the required lower bound.
The state returned on this branch is \((y,m)\), not the identity element
\(w\).

## 4. Uniform quasipolynomial cost

A sieve through \(T\) lists all primes at most \(T\) and constructs

\[
\Lambda_T=\prod_{r\le T}r^{\lfloor\log_rT\rfloor}
\tag{10}
\]

with its complete factorization. The elementary bound

\[
\log_2\Lambda_T=O(T\log T)
\tag{11}
\]

is enough here. Hence

\[
\log_2Q=O(nT\log T).
\tag{12}
\]

The number of prime-division attempts in factor-first stripping is at most

\[
n\sum_{r\le T}\lfloor\log_rT\rfloor=O(nT\log T).
\tag{13}
\]

Every modular exponent has an exponent of \(O(nT\log T)\) bits and a
modulus of \(n\) bits. The sieve, construction, modular powers, gcds, and
all stripping tests therefore use a polynomial in \(n,T,\log T\) number of
bit operations. Since \(T\) is one fixed numerical quasipolynomial in
\(n\), the total cost is uniform deterministic quasipolynomial.

## 5. Nonunit-free shift-three corollary

Fix \(\ell^a\parallel g_j\). For

\[
B_3=(N+3)\prod_{k=1}^K((N+3)^k-1),
\]

the prime \(\ell\) divides \(B_3\) exactly when either

\[
\ell\mid N+3
\]

or \(N+3\) is a unit modulo \(\ell\) with

\[
\operatorname{ord}_\ell(N+3)\le K.
\]

As before, the outer \(n\)-th power removes the complete \(\ell^a\) part.
Thus every surviving primary part is a unit long-period part.

Now assume that both the \(A_0\) and \(B_3\) filters are the identity on
every hidden component. The first identity says that for every
\(\ell^a\parallel g_j\), some \(k\le K\) satisfies

\[
N^k\equiv1\pmod\ell.
\tag{14}
\]

If \(\ell\mid N+3\), then \(N\equiv-3\pmod\ell\), and (14) gives

\[
\ell\mid 3^k-(-1)^k=S_k.
\tag{15}
\]

Otherwise, the second identity supplies \(l\le K\) with

\[
(N+3)^l\equiv1\pmod\ell.
\tag{16}
\]

Equations (14) and (16), together with the Sylvester-matrix Bezout identity,
give

\[
\ell\mid
\left|\operatorname{Res}_X
\bigl(X^k-1,(X+3)^l-1\bigr)\right|.
\tag{17}
\]

The two polynomials have no common complex root, because such a root \(u\)
would satisfy \(|u|=|u+3|=1\), while \(|u+3|\ge2\). Thus every resultant
is nonzero. The standard root product gives it \(O(K^2)\) bits; each
\(S_k\) has \(O(K)\) bits. Trial division of all \(K+K^2\) integers costs
\(2^{O(K^2)}\), which is quasipolynomial for (11) of the statement.

Every prime supporting every \(g_j\) occurs in this fully factored product.
Its \(n\)-th power supplies all primary multiplicities because each exponent
is below \(n\). Factor-first stripping therefore returns a proper factor or
one exact common order. That order is above \(T\) by (9) of the statement.
This proves the separate corollary.
