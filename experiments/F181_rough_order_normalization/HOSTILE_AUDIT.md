## Hostile checks

### Imported P160 interface and arbitrary prime powers

The proof uses exactly the P160 hard-branch data:

\[
1<f_j<N<2^n,
\qquad
\gcd(f_j,N)=1,
\qquad
\sigma(f_j)>T.
\]

Let \(R_j=p^b\). Every order occurring after the new power map divides
\(f_j\), so it is coprime to \(p\). The reduction kernel

\[
(\mathbb Z/p^b\mathbb Z)^\times
\longrightarrow
(\mathbb Z/p\mathbb Z)^\times
\]

is a \(p\)-group. Its intersection with the cyclic subgroup generated by
any such powered element is therefore trivial. A tested power is one
modulo \(p\) exactly when it is one modulo \(p^b\). This validates every
endpoint interpretation of the gcd screens for repeated prime factors; no
squarefree assumption is hidden.

### Exact effect of \(Q=\Lambda_T^n\)

Fix \(\ell^a\parallel f_j\). Since

\[
2^a\le \ell^a\le f_j<N<2^n,
\]

one has \(a<n\). If \(\ell\le T\), then

\[
v_\ell(Q)
=n\lfloor\log_\ell T\rfloor
\ge n>a,
\]

so the complete \(\ell^a\)-part is deleted. If \(\ell>T\), then
\(v_\ell(Q)=0\), so the complete part is preserved. The order-of-a-power
formula consequently gives exactly

\[
\operatorname{ord}_{R_j}(y^Q)
=\prod_{\substack{\ell^a\parallel f_j\\ \ell>T}}\ell^a.
\]

The outer power \(n\) is essential: it also deletes a large primary power
\(\ell^a>T\) whose supporting prime satisfies \(\ell\le T\). The candidate
does not confuse bounded prime support with bounded primary size.

### The three \(H\)-branches

Write the displayed filtered order as \(g_j\). The prime-power reduction
argument above shows that

\[
H=\gcd(w-1,N)
=\prod_{g_j=1}R_j.
\]

Thus \(1<H<N\) is a proper factor, including for a pure prime power where
a partial gcd would also already suffice. If \(H=1\), every \(g_j\) is
nontrivial. All its prime divisors exceed \(T\), so

\[
P^-(g_j)>T,
\qquad
g_j>T,
\qquad
\gcd(g_j,N)=1.
\]

If \(H=N\), every prime supporting every \(f_j\) is at most \(T\).
The valuation calculation above then gives \(f_j\mid Q\) for all hidden
components. These cases are exhaustive.

### Factor-first recovery from the factored annihilator

The sieve supplies the complete factorization

\[
Q=\prod_{r\le T}r^{n\lfloor\log_rT\rfloor}.
\]

Maintain a current exponent \(m\) divisible by all local orders. For a
prime \(r\mid m\), a global value of

\[
\gcd(y^{m/r}-1,N)
\]

permits deletion of one copy of \(r\), while a proper value factors \(N\).
If the value is one, no local order divides \(m/r\). Since every local
order still divides \(m\), every one has the full current \(r\)-adic
valuation. Therefore, on a no-factor run, the terminal valuation at each
prime equals the valuation in every \(f_j\). The terminal exponent is
their exact common order:

\[
m=f_j\qquad(1\le j\le s).
\]

Its factorization is inherited from that of \(Q\). The inherited premise
\(\sigma(f_j)>T\) then gives \(m>T\). The returned element must be the
original \(y\), as stated, rather than the identity \(w\).

### Numerical-QP cost

A sieve through the fixed numerical quasipolynomial value \(T\) takes a
number of bit operations polynomial in \(T\) and \(\log T\). The loose
bound

\[
\log Q=O(nT\log T)
\]

puts construction and every modular exponentiation within QP cost. The
total number of successful deletions and terminal prime tests is at most
the total multiplicity in the known factorization of \(Q\), hence
\(O(nT\log T)\). Thus the procedure is uniform deterministic QP for each
fixed, effectively specified numerical-QP choice of \(T\). It does not
use a numerical-QP exponent as a unary hidden input.

### Separate nonunit-free shift corollary

For \(\ell^a\parallel g_j\), the factor

\[
B_3=(N+3)\prod_{k=1}^K((N+3)^k-1)
\]

is divisible by \(\ell\) exactly when either \(\ell\mid N+3\), or
\(N+3\) is a unit modulo \(\ell\) with order at most \(K\). The exponent
\(B_3^n\) then deletes all \(a<n\) copies. Hence every surviving prime is
a unit for \(N+3\) and has period above \(K\). For the zero shift,
\(\gcd(g_j,N)=1\) already excludes the nonunit case.

If both filters are globally the identity, every prime \(\ell\) supporting
every \(g_j\) divides both filter bases. The zero-shift identity supplies
some \(k\le K\) with \(N^k\equiv1\pmod\ell\). If
\(\ell\mid N+3\), then

\[
\ell\mid 3^k-(-1)^k.
\]

Otherwise the second identity supplies \(l\le K\) with
\((N+3)^l\equiv1\pmod\ell\), and the common root \(N\pmod\ell\) gives

\[
\ell\mid
\operatorname{Res}_X(X^k-1,(X+3)^l-1).
\]

Every resultant is nonzero: a common complex root would have both
\(|u|=1\) and \(|u+3|=1\), while \(|u+3|\ge2\). Its bit length is
\(O(K^2)\), and each \(3^k-(-1)^k\) has \(O(K)\) bits. Trial division of
all \(K+K^2\) integers costs \(2^{O(K^2)}\), which is QP for the stated
fixed \(K=(\log n)^{O(1)}\). Raising their fully factored product to the
\(n\)-th power supplies every local primary multiplicity. Factor-first
stripping therefore yields a factor or the common exact order of \(w\),
which is above \(T\) because every rough \(g_j>T\).

The two filters are applied to the same rough source \(w\). The proof does
not incorrectly apply the second filter to an identity descendant.
