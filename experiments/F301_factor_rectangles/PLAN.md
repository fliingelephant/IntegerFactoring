# Direct factor-isolating rectangles and bounded rational filters

**Family:** route:F31

The fifth cycle must retain the original factoring instance. F294--F299
operate inside individual charts and leave both outer chart aggregation and
the original factor-isolating windows. This packet specifies an all-input
public rectangular decision interface and tests it on the original modulus
M approximately N, rather than only full chart half-windows.

The root's construction uses ratio17/16 boxes whose products lie strictly
between N-M and N+M. A nonempty congruence rectangle then contains only true
factor pairs. Its exact statement is being checked by a fresh statement-only
Sol; the oracle remains an unimplemented research obligation.

A second root candidate replaces integer interval indicators by uniformly
bounded rational filters of polynomial degree. This may permit analytic
resolvent methods without enumerating all Fourier frequencies. A short
filter is not, by itself, an efficient modular-inverse-graph sum.

Implementation support will preserve a deterministic reference oracle,
exact public coverage tests, seeded controls, cost counters, sources, logs,
and outputs. The reference oracle's enumeration cost must remain visible.
No hidden factor label may select a box or an algorithmic action.
