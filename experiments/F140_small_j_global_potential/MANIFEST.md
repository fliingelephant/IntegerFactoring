## Candidate claim

For infinitely many semiprimes, an already named small block can start a
deterministic selected path of \(\Omega(n^{1/3})\) consecutive public
cross-star releases with quotient one.  Every selected exact value is new,
all relevant endpoint screens are null, and the selected parity matrix has
full column rank through public valuation-one private rows.

This is a selected-path obstruction.  It is not a complete-source null, a
polynomial lower bound for every selector, or a factoring algorithm.
